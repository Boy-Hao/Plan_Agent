# 01 第一主线：身份、权限与租户

> 定位：**T0 生死线**。它决定「谁能进、能看什么、能不能越权」，是所有模块的地基。
> 失败后果：数据泄露、越权操作、审计不通过；不能靠后补。

---

## 1. 成败标准

| 标准 | 目标 |
|---|---|
| 登录成功率 | ≥99.9% |
| 越权成功 | 0 |
| 跨租户成功 | 0 |
| 权限变更生效 | ≤10s（缓存 TTL 兜底） |
| 高危操作审计 | 100% |
| 密钥泄露 | 0 |

---

## 2. 身份平面

```
浏览器/飞书/A2A/API
  ↓
Edge（TLS/WAF）
  ↓
Auth（SSO/JWT/API Key/Bridge）
  ↓
TenantContext + UserContext + Permissions
  ↓
业务 API（RBAC + ACL + DataScope）
```

**原则**：认证只做一次；上下文不可伪造；业务层不信任前端传的 tenant/user/owner。

---

## 3. 认证方式（按主次）

| 方式 | 优先级 | 用途 | 失败 |
|---|---|---|---|
| OIDC SSO + JWT | P0 | Web/H5 | 跳 SSO |
| Refresh | P0 | 静默续期 | 重新登录 |
| API Key HMAC | P1 | 系统集成 | 401 |
| Bridge | P2 | 嵌入 | 宿主续 token |
| A2A Bearer | P2 | Agent 间 | 401 |
| 服务 token/mTLS | P1 | 内部 | 拒绝 |

### 3.1 JWT 设计

```json
{
  "sub": "u1",
  "tenant_id": "t1",
  "roles": ["content_creator"],
  "permissions": ["agent:view","agent:chat"],
  "jti": "j1",
  "iss": "cloud-agent",
  "aud": "web",
  "exp": 1760001800
}
```

- access 15–30min；refresh 7–30d。
- 固定算法；校验 iss/aud/exp；禁止 none。
- Redis 存会话存在性，支持登出/封禁立即失效。
- 权限放 token 或 Redis 缓存；变更清缓存。

### 3.2 刷新并发

- 前端多个 401 → 只触发一次 refresh。
- refresh 失败 → 清 token → SSO。
- refresh 轮换；检测重放。

## 4. 租户模型

### 4.1 级别

| 级别 | 隔离 | 适用 | 成本 |
|---|---|---|---|
| L1 | 共享表 + tenant_id | 首版/SaaS 小租户 | 低 |
| L2 | 共享库 + 独立 schema | 中大型 | 中 |
| L3 | 独立库 | 大客户/合规 | 高 |
| L4 | 独立部署 | 私有化 | 最高 |

**建议**：首版 L1，但所有表/缓存/OSS/日志带 tenant_id，预留 L2/L3。

### 4.2 强制规则

- 网关解析租户（域名/Token claim/Header），写入不可变 `TenantContext`。
- 禁止从 body/query 接收 tenant_id（除超管跨租户）。
- Repository 默认注入 `tenant_id`；裸 SQL 禁止。
- Redis key：`t:{tenant}:...`。
- OSS：`/{tenant}/...`。
- 日志/指标：`tenant_id` 字段。
- CI：跨租户测试，0 成功。

---

## 5. RBAC

### 5.1 模型

```
user ── user_role ── role ── role_permission ── permission
```

### 5.2 角色（建议）

| 角色 | 能力 |
|---|---|
| super_admin | 全部；审计管理 |
| content_admin | 内容/资源全部 |
| content_creator | 创建/管理自己/协作 |
| user | 使用 |
| db_super_admin | 权限审计（独立） |

### 5.3 权限码

`资源:动作`；分组 `group_code`；前端勾选树；后端强校验。
示例：`agent:view/chat/update`、`skill:view`、`llm_config:view`、`sandbox:admin`、`role:manage`、`api_key:manage`、`usage:admin`、`oss:file:govern`。

### 5.4 校验顺序

```
登录 → 功能权限 → 资源可见性 → 数据范围 → 业务状态
```

- 前端隐藏只是体验；后端必须校验。
- 无权资源返回 404（防枚举）；明确越权 403。

---

## 6. 资源 ACL

| 动作 | owner | collaborator | public | admin |
|---|---|---|---|---|
| view | ✅ | ✅ | ✅ | ✅ |
| edit | ✅ | ✅ | ❌ | ✅ |
| delete | ✅ | ❌ | ❌ | ✅ |
| manage | ✅ | ❌ | ❌ | ✅ |

**规则**
- 协作者幂等；软删后复用。
- 转移 owner 需目标有创建权限。
- 删除前展示影响（会话/调度/子 Agent）。
- ACL 变更审计。

---

## 7. 数据范围

| 角色 | 会话/用量 |
|---|---|
| super/content_admin | 全部 |
| content_creator | 自己 + 协作 |
| user | 自己 |

- 列表查询强制过滤；详情校验归属。
- 管理员跨范围操作审计。
- 导出/批量操作逐项校验。

---

## 8. API Key

```
Authorization: XPD-HMAC-SHA256 app_id=..., timestamp=..., nonce=..., signature=...
signature = HMAC-SHA256(secret, app_id\ntimestamp\nnonce\nmethod\npath\nbody_sha256)
```

- 时间窗 ±5min；nonce 防重放。
- scope：blocking/sessions/agents/a2a/access_token。
- allowed_agents 限制。
- secret 只创建时返回一次；列表掩码。
- 轮换/禁用/删除立即生效。

---

## 9. 审计

| 事件 | 记录 |
|---|---|
| 登录/登出/失败 | user/ip/ua/result |
| 角色/权限变更 | 前值/后值 |
| 密钥操作 | 创建/轮换/禁用（不含明文） |
| 资源删除/转移 | 影响范围 |
| 跨租户操作 | 操作人/原因 |

- 保留 ≥1 年；防篡改；导出脱敏。
- 高危操作可同步写/阻断。

---

## 10. 失败模式

| 失败 | 行为 |
|---|---|
| SSO 不可用 | 已有会话继续；新登录提示 |
| JWT 过期 | 401 → refresh → 重放 |
| refresh 失效 | 清 token → SSO |
| Redis 故障 | 会话校验降级/拒绝 |
| 权限缓存脏 | TTL + 主动失效 |
| 跨租户 | 403/404 + 告警 |
| API Key 重放 | 401 + 告警 |

---

## 11. 实施顺序（T0 内）

1. 表/迁移：user/role/permission/role_permission/user_role。
2. SSO 登录/回调/refresh/logout。
3. `/auth/me/permissions` + 前端守卫。
4. RBAC 中间件 + 权限码。
5. 资源 ACL + 数据范围。
6. 审计日志。
7. API Key（P1）。
8. Bridge/A2A（P2）。

---

## 12. 验收用例

- [ ] 未登录 401；过期 401→刷新→成功。
- [ ] 普通用户访问管理接口 403。
- [ ] 访问他人私有 Agent 404/403。
- [ ] 协作者可编辑不可删。
- [ ] 转移 owner 后权限正确。
- [ ] 跨租户 0 成功。
- [ ] 角色变更 10s 内生效。
- [ ] API Key 错签/重放/越权 401/403。
- [ ] 高危操作可审计/导出。
- [ ] 密钥不落日志/前端。
