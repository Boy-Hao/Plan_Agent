# 04 第一主线：Skill 与 MCP 工具链

> 定位：**T0 生死线**。它决定「工具怎么被发现、怎么被选、怎么安全调用」。
> 失败后果：模型选错工具、工具注入、越权、上下文爆炸、结果不可用。

---

## 1. 成败标准

| 标准 | 目标 |
|---|---|
| 工具选择准确率 | ≥90%（核心场景） |
| 工具调用成功率 | ≥95% |
| 平均工具数 | ≤5（单轮） |
| 工具结果超限 | 0（有截断） |
| 越权工具调用 | 0 |
| MCP 故障阻塞 | 0（可降级） |
| Skill 注入 | 0（扫描/隔离） |

---

## 2. 工具链全景

```
注册（Skill/MCP/内置/HTTP）
  ↓
发现（list/健康/权限）
  ↓
筛选（能力/可用/暴露）
  ↓
选择（意图/召回/重排/Top-K）
  ↓
执行（参数/权限/超时/沙箱）
  ↓
观察（结果/错误/压缩）
  ↓
治理（版本/审计/评估）
```

---

## 3. 工具注册

### 3.1 来源

| 来源 | 注册方式 | 版本 |
|---|---|---|
| 内置 | 代码注册表 | 代码版本 |
| Skill | 上传/GitLab | skill_version |
| MCP | 配置/发现 | server 版本 |
| HTTP | 工具配置 | 配置版本 |

### 3.2 统一元数据

```json
{
  "name": "query_bom",
  "alias": "bom__query",
  "description": "查询指定车型的 BOM 行；只在用户问 BOM 时使用",
  "tags": ["bom", "query"],
  "risk": "read",
  "input_schema": {},
  "output_schema": {},
  "timeout_ms": 30000,
  "requires": {"sandbox": false, "mcp": "xbom"},
  "owner": "team-a",
  "version": 3
}
```

---

## 4. 发现与筛选

```
全部工具
→ 权限（用户/Agent/租户）
→ 能力（模型支持 tool calling）
→ 可用性（Skill 启用/MCP 健康/沙箱）
→ 暴露（all/selected）
→ 数量上限（如 30）
→ Top-K（如 5–15）
```

**原则**：先过滤再选择；不要把不可用/无权的工具给模型。

---

## 5. 工具选择

### 5.1 规则

- 明确命令（`/skill`）→ 直接。
- 关键词/领域 → 白名单。
- 结构化参数 → 正则/解析。

### 5.2 召回/重排

```
意图 → 标签/关键词/向量召回 → 规则/LLM 重排 → Top-K
```

**工具多时**：Tool RAG；**工具少时**：全量。

### 5.3 描述

- 只写「何时用/不用」；不写长文档。
- Schema 完整；示例。
- 冲突加前缀；稳定命名。

---

## 6. 执行

```
模型 tool_call
→ 校验名称/参数/权限/风险/配额
→ 记录 pending（幂等）
→ 执行（超时/重试/取消）
→ 结果脱敏/截断/落 OSS
→ 记录 done
→ 回填模型
```

- 只读并行；写串行；高危确认。
- 失败返回结构化错误。
- 结果大小限制。
- 循环检测（相同工具+参数）。

---

## 7. Skill 执行模式

| 模式 | 加载 | 适用 |
|---|---|---|
| inline | 注入说明 | 轻量 |
| on_demand | 按需读取 | 中等 |
| subagent | 独立会话 | 复杂 |

**沙箱要求**：required/optional/none；required 必须可用。

---

## 8. MCP

- HTTP/SSE/stdio（stdio 仅开发）。
- Header 只存变量引用。
- all/selected；超时/重试/熔断。
- 故障跳过，不阻塞整轮。
- 工具结果按数据处理，防注入。

---

## 9. 安全

| 风险 | 控制 |
|---|---|
| 工具注入 | 描述/结果标记为数据 |
| 越权 | 工具级 scope + Agent 授权 |
| 密钥泄露 | 变量引用/加密/脱敏 |
| SSRF | URL 白名单 |
| 恶意 Skill | 扫描/沙箱/审核 |
| 滥用 | 限流/配额/超时 |
| 供应链 | 版本/签名/评估 |

---

## 10. 失败与降级

| 失败 | 行为 |
|---|---|
| 工具不可用 | 过滤/跳过/替代 |
| 参数错 | 返回错误给模型 |
| 超时 | 返回超时；重试 1 次 |
| 结果过大 | 截断/OSS |
| MCP 断 | 熔断；其他工具继续 |
| Skill 被删 | 标记不可用；提示 |
| 循环 | 检测并停止 |

---

## 11. 治理

- Skill 版本/回滚/评估/风险。
- MCP 配置/测试/启停/密钥轮换。
- 工具调用审计/用量/失败 TopN。
- 工具描述/参数变更版本化。
- 评估：选择准确率/参数正确率/成功率。

---

## 12. 实施顺序

1. 工具注册表 + 内置工具。
2. Skill 上传/解析/绑定（inline/on_demand）。
3. 工具调用 + 结果压缩。
4. MCP 配置/测试/发现/调用。
5. Tool RAG/Top-K（工具多时）。
6. 审计/评估/治理。
7. subagent 模式（P2）。
