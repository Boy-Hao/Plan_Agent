# 05 第二主线：沙箱、文件与数据

> 定位：**T1 支撑线**。没有它，代码任务不能跑、附件不能存、数据不能规模化。
> 失败后果：逃逸、数据丢失、成本失控、数据库拖垮。

---

## 1. 成败标准

| 标准 | 目标 |
|---|---|
| 沙箱创建成功率 | ≥99% |
| 沙箱隔离 | 0 逃逸 |
| 文件上传成功率 | ≥99% |
| 签名 URL 越权 | 0 |
| 数据丢失 | 0（可恢复） |
| 单轮 DB 写入 | ≤5 |
| 消息查询 P95 | ≤500ms |

---

## 2. 沙箱

### 2.1 生命周期

```
lazy/prewarm → provisioning → running → paused → deleted
```

- lazy：首次创建；prewarm：池取。
- 空闲暂停；暂停后销毁。
- 定时 reconcile 清理孤儿。
- 重置可预览影响。

### 2.2 隔离

- microVM/gVisor；独立文件/网络。
- 默认无公网；出站白名单。
- 禁内网/元数据/K8s API。
- 资源限额；超限终止。
- 镜像签名/扫描/固定 digest。

### 2.3 凭证

- 不注入长期密钥。
- Git 短期租约（caller/platform）。
- 模型走 LLM 代理。
- 任务结束清理。

### 2.4 模式

| 模式 | 适用 |
|---|---|
| lazy | 默认 |
| prewarm | 高并发 |
| shared | 短任务（风险） |
| ttl | 短任务 |
| platform_idle | 交互 |

---

## 3. 文件

### 3.1 上传

- 预签名直传（默认）/后端中转/分片。
- 类型/大小/病毒扫描。
- 对象 key 不可猜。
- 配额。

### 3.2 访问

- 私有 Bucket。
- 签名 URL（5–15min）。
- 预览/下载分离。
- 跨租户/跨用户 403。

### 3.3 生命周期

- 回收站 30 天。
- 版本保留 30 天。
- 临时文件 7 天。
- 盘点/孤儿/回收。

---

## 4. 数据

### 4.1 一致性

- 聚合内强一致；跨聚合最终一致（outbox）。
- 消息/用量/审计同事务 outbox。
- 幂等键。

### 4.2 分区

| 表 | 策略 |
|---|---|
| message | 月 + session hash |
| usage | 月 |
| audit | 月 |
| trace | 天 |

### 4.3 索引

- 会话列表：`(tenant,user,is_deleted,last_active)`。
- 消息：`(tenant,session,seq)`。
- 用量：`(tenant,create_time)`。
- 审计：`(tenant,resource,time)`。

### 4.4 备份

- MySQL 全备+binlog；RPO≤15s。
- Redis AOF/RDB。
- OSS 版本/跨区。
- 季度恢复演练。

---

## 5. 失败模式

| 失败 | 行为 |
|---|---|
| 沙箱创建失败 | 重试/降级只读 |
| 沙箱泄漏 | 批量 kill/隔离 |
| 文件上传失败 | 重试/提示 |
| 签名过期 | 重新获取 |
| OSS 故障 | 重试/降级 |
| DB 慢 | 限流/索引/归档 |
| 数据不一致 | 对账/补偿 |

---

## 6. 实施顺序

1. 文件上传/签名/附件。
2. 消息/用量分区。
3. 沙箱配置/生命周期。
4. 沙箱任务/日志/取消。
5. Git 租约/LLM 代理。
6. 回收站/版本。
7. 盘点/孤儿/回收。
8. 备份/恢复演练。
