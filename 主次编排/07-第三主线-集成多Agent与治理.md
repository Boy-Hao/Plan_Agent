# 07 第三主线：集成、多 Agent 与治理

> 定位：**T2 增强线**。没有它系统仍可用，但进不了工作流、规模化和合规。
> 前提：T0/T1 已达标；否则不要启动。

---

## 1. 成败标准

| 标准 | 目标 |
|---|---|
| 飞书消息成功率 | ≥99% |
| 飞书 WS 重连 | ≤30s |
| GitLab 同步成功率 | ≥99% |
| A2A 调用成功率 | ≥99% |
| 多 Agent 任务完成率 | ≥85% |
| 审计覆盖高危 | 100% |
| OSS 孤儿回收 | 可审计/可恢复 |

---

## 2. 集成优先级

| 集成 | 优先级 | 理由 |
|---|---|---|
| 飞书机器人 | P1（T2 首） | 主要入口 |
| 飞书 OAuth/推送 | P1 | 授权/通知 |
| GitLab 同步/OAuth | P2 | 研发场景 |
| A2A | P2 | 跨系统 |
| 调度/数据页 | P2 | 自动化 |
| 图表/BI | P3 | 增强 |

---

## 3. 飞书

### 3.1 机器人

- app_id/secret/encrypt/verification。
- WS 长连接；单活跃连接（锁/租约）。
- 消息 → 绑定用户 → Agent → SSE/卡片。
- 未绑定 → bind_nonce。
- 失败：重连/提示。

### 3.2 OAuth

- Web：prepare → authorize → callback。
- 内嵌：prompt_id → owner。
- token 加密/刷新/撤销。
- primary 切换 revoke 旧 token。

### 3.3 推送

- 模板/卡片 JSON。
- 部门/用户/组；open_id 解析。
- 批次/进度/阅读/撤回。
- 频率限制/二次确认。

---

## 4. GitLab

- Skill 同步：配置/预览/执行/冲突/重试。
- OAuth：授权/状态/撤销。
- 编码账号：PAT/项目白名单/租约。
- MR：沙箱 → 平台创建 → 链接。

---

## 5. A2A

- Agent Card 公开；Bearer 认证。
- 消息流；限流/超时。
- 不暴露内部地址/密钥。
- 与内部 Runtime 同源取消/续跑。

---

## 6. 多 Agent

### 6.1 何时用

| 场景 | 建议 |
|---|---|
| 1–5 步工具 | 单 Agent |
| 可并行子任务 | 单 Agent + 并行工具 |
| 跨领域/长任务 | 多 Agent |
| 高风险 | 多 Agent + 人工 |

### 6.2 设计

- Supervisor 起步。
- 计划 DAG + 预算 + 验收。
- 子 Agent 独立上下文。
- 父收摘要/引用。
- 失败重试/跳过/重规划。

### 6.3 成本

多 Agent 通常更贵；先证明单 Agent 不够。

---

## 7. 治理

### 7.1 权限审计

- 申请/审批/授权/到期/回收。
- 高危权限双人审批。
- 证据/导出。

### 7.2 OSS 治理

- 盘点/孤儿/归属/回收。
- 容量/门禁。
- 审计/恢复。

### 7.3 审计

- 高危操作 100%。
- 保留 ≥1 年。
- 导出脱敏。

---

## 8. 失败模式

| 失败 | 行为 |
|---|---|
| 飞书 WS 断 | 重连；Web 可用 |
| token 过期 | 刷新/重新授权 |
| 推送部分失败 | 批次重试 |
| GitLab 5xx | 熔断/重试 |
| A2A 401 | 换 token |
| 子 Agent 循环 | 检测/停止 |
| 审计缺失 | 阻断高危操作 |

---

## 9. 实施顺序

1. 飞书机器人/WS/绑定。
2. 飞书 OAuth/推送。

4. A2A。
5. 多 Agent（Supervisor）。
6. 调度/数据页。
7. 权限审计/OSS 治理。
