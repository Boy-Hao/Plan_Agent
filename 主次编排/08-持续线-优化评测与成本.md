# 08 持续线：优化、评测与成本

> 定位：**T3 优化线**。没有它系统仍能用，但会越来越贵、越来越慢、越改越差。
> 前提：T0/T1 稳定；有基线、有评测、有灰度。

---

## 1. 成败标准

| 标准 | 目标 |
|---|---|
| 单任务成本 | 季度下降 10–20% |
| 首 token P95 | 不退化 |
| 任务完成率 | 不下降 >2% |
| 缓存命中率 | 持续提升 |
| 质量回归 | 每次变更必跑 |
| 优化可归因 | 100% |

---

## 2. 基线（先测再优）

| 指标 | 采集 |
|---|---|
| TTFT/完整延迟 | P50/P95 |
| token/请求 | 输入/输出/缓存 |
| 单任务成本 | 按 Agent/模型 |
| 工具轮次 | 平均/分布 |
| 错误/超时/降级 | 分类 |
| 质量 | 完成率/点赞/引用 |

**没有基线，不做优化。**

---

## 3. 优化顺序（主次）

### 3.1 P0（低风险快收益）

1. 稳定 Prompt 前缀 + Provider 缓存。
2. 历史摘要 + 工具结果裁剪。
3. SSE 合并 + 防代理缓冲。
4. DB 批量写 + 索引。
5. max_output + 轮次/工具上限。
6. 沙箱 lazy/暂停 + 存储生命周期。
7. 熔断/降级 + 调用链。

### 3.2 P1（结构性）

1. 工具 Top-K/Tool RAG。
2. 难度分类 + 模型级联。
3. 并行工具/检索。
4. 独立 SSE 网关。
5. 检索/Embedding 缓存。
6. 分区/归档。

### 3.3 P2（实验性）

1. 语义缓存（严格护栏）。
2. 学习型路由（数据足够）。
3. 多 Agent 计划模板。
4. 引用片段化/重排优化。

---

## 4. 成本模型

```
cost = LLM + 沙箱 + 基础设施 + 存储/流量
单任务成本 = 总成本 / 成功任务数
```

- 看单任务成本，不看单 token。
- 按租户/Agent/模型归因。
- 预算/告警/配额。
- 与供应商账单对账。

---

## 5. 评测

| 层 | 内容 |
|---|---|
| 规则 | 格式/工具/参数 |
| Golden Set | 100–300 任务 |
| LLM Judge | rubric/校准 |
| 人工 | 抽样/高风险 |
| 线上 | 点赞/重试/放弃 |

**门禁**：质量下降 >2% 阻断；成本上升 >10% 复核。

---

## 6. 实验

```
离线回归 → 影子 → 金丝雀 → A/B → 全量
```

- 一次 1–2 个变量。
- 看置信区间，不只看均值。
- 失败可回滚。
- 记录实验结论。

---

## 7. 30/60/90

| 阶段 | 重点 |
|---|---|
| 0–30 天 | 缓存/摘要/裁剪/SSE/DB/预算/熔断 |
| 31–60 天 | Tool RAG/级联/并行/独立网关/检索缓存/分区 |
| 61–90 天 | 引用/重排/语义缓存（小范围）/计划模板/容量 |

---

## 8. 反优化

| 反优化 | 原因 |
|---|---|
| 过早微服务 | 复杂 > 收益 |
| 全量语义缓存 | 一致性/隐私 |
| 盲目多 Agent | 贵/慢 |
| 过度压缩 | 质量降，重试更贵 |
| 只看单价 | 任务成本更高 |
| 无评测调 Prompt | 无法证明 |
| 全量日志长保留 | 存储成本 |

---

## 9. 失败模式

| 失败 | 行为 |
|---|---|
| 质量下降 | 回滚 |
| 成本反升 | 复核 |
| 缓存脏 | 失效/回滚 |
| 评测偏差 | 人工校准 |
| 实验污染 | 隔离/重置 |

---

## 10. 验收

- [ ] 有基线/看板。
- [ ] 每次变更跑评测。
- [ ] 优化有质量/成本/延迟三指标。
- [ ] 实验可灰度/回滚。
- [ ] 单任务成本可归因。
- [ ] 质量不降。
