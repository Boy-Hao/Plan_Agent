# 09 执行编排：12 周与 28 周

> 按主次编排的落地节奏：先 T0，再 T1，再 T2，最后 T3。
> 每周有明确交付、验收人、门禁；不按「功能想做」排。

---

## 1. 团队与并行

| 角色 | 人数 | 主线 |
|---|---|---|
| 架构/TL | 1 | 全部 |
| 后端 A | 2 | 身份/Agent/权限 |
| 后端 B | 2 | 运行时/模型/Skill |
| 前端 | 2–3 | 工作台/对话/管理端 |
| AI | 1–2 | Runtime/工具/评测 |
| SRE | 1 | 环境/CI/监控 |
| QA | 1 | 自动化/压测 |
| 产品/设计 | 1–2 | 需求/验收 |

**并行原则**：T0 内部可并行（身份/模型/运行时），但 T2 必须等 T0/T1 门禁。

---

## 2. 12 周：可用系统

### 第 1 周：骨架

| 线 | 交付 |
|---|---|
| 后端 | 仓库/配置/DB/迁移/健康检查 |
| 前端 | 骨架/路由/布局/登录页 |
| SRE | CI/环境/监控 |
| 架构 | 主次/接口/数据评审 |

**门禁**：本地 1 小时跑起来。

### 第 2 周：身份（T0）

- SSO/回调/refresh/logout。
- 用户/角色/权限表。
- `/auth/me/permissions`。
- 前端守卫。

**门禁**：不同角色菜单不同；越权 403。

### 第 3 周：Agent + 模型（T0）

- Agent CRUD/可见性。
- 模型配置/测试/绑定。
- 管理端页面。

**门禁**：创建 Agent 并绑定模型。

### 第 4 周：权限/ACL + 模型加密

- 资源 ACL/协作者。
- 密钥加密/掩码。
- 审计日志。

**门禁**：跨用户/跨租户 0 成功。

### 第 5 周：会话 + SSE（T0）

- Session/Message/Turn。
- SSE 流式/持久化。
- 前端对话页。

**门禁**：多轮对话可用。

### 第 6 周：续传/取消/并发

- ring buffer/active-turn/live。
- 取消/幂等/锁。
- 刷新恢复。

**门禁**：断网 30s 恢复；无双轮。

### 第 7 周：Skill（T0）

- 上传/解析/绑定。
- inline/on_demand。
- 前端 Skills 页。

**门禁**：真实 Skill 调用成功。

### 第 8 周：MCP + 工具（T0）

- MCP 配置/测试/发现/调用。
- 工具过滤/结果裁剪。
- Tool RAG（如需要）。

**门禁**：MCP 工具可调用；故障不阻塞。

### 第 9 周：文件 + 沙箱（T1）

- 上传/签名/附件。
- 沙箱配置/lazy/任务。
- Git 租约/LLM 代理。

**门禁**：附件可用；沙箱隔离。

### 第 10 周：配额 + 管理端（T1）

- 配额 OBSERVE。
- 用量/成本。
- 管理端完善。

**门禁**：配额可观测；成本可归因。

### 第 11 周：可观测 + 压测（T1）

- 指标/日志/Trace。
- 告警/值班。
- 200 并发/5k SSE/100 沙箱。

**门禁**：P95 达标；告警可用。

### 第 12 周：安全 + 上线

- 越权/密钥/沙箱扫描。
- 灰度/回滚。
- 种子用户/培训。

**门禁**：上线清单通过；M1。

---

## 3. 13–28 周：平台化/集成/规模化

### 13–16 周：T1 深化

- 分区/归档/备份演练。
- 配额 ENFORCE/对账。
- 沙箱预热/共享池。
- 管理端审计/系统参数。

**门禁**：M2（20–50 用户）。

### 17–20 周：T2 首批

- 飞书机器人/WS/绑定。
- 飞书 OAuth/推送。
- 权限审计（基础）。

**门禁**：飞书试点。

### 21–24 周：T2 扩展

- GitLab 同步/OAuth/MR。
- A2A。
- 多 Agent（Supervisor）。
- 调度/数据页。
- OSS 治理。

**门禁**：M3（业务试点）。

### 25–28 周：T3 + GA

- 优化（缓存/级联/成本）。
- 评测/实验。
- 压测/安全/容灾。
- 灰度/全量。

**门禁**：M4（GA/SLO）。

---

## 4. 每周节奏

| 日 | 活动 |
|---|---|
| 周一 | 计划/风险/依赖 |
| 周二–四 | 开发/联调 |
| 周五 | Demo/验收/复盘 |

**规则**
- 每周一个可演示增量。
- 阻塞 24h 升级。
- 门禁不通过不带病进下一周。

---

## 5. 门禁清单

| 门禁 | 条件 |
|---|---|
| G0 骨架 | 本地跑起来 |
| G1 身份 | 越权 0 |
| G2 Agent/模型 | 绑定可对话 |
| G3 运行时 | 续传/取消/无双轮 |
| G4 Skill/MCP | 工具可调用/可降级 |
| G5 沙箱/文件 | 隔离/签名/回收 |
| G6 配额 | 不超发/可归因 |
| G7 可观测 | 指标/告警/值班 |
| G8 集成 | 飞书/GitLab 试点 |
| G9 GA | 压测/安全/灰度 |

---

## 6. 风险与调整

| 风险 | 调整 |
|---|---|
| T0 延期 | 砍 T2，不砍 T0 |
| 模型不稳 | 多 Provider/降级 |
| 沙箱不稳 | 后置/只读工具 |
| 集成卡住 | Mock/后置 |
| 成本超 | 配额/降级 |
| 人员不足 | 砍范围，不砍质量门禁 |

- [ ] 28 周路线与主次一致。
