# 59 缓存与复用架构

## 1. 缓存分层

```
Browser/CDN
  ↓
应用本地缓存（LRU，进程内）
  ↓
Redis（共享缓存/锁/配额/SSE）
  ↓
DB（源数据）
  ↓
OSS（大对象）
  ↓
Provider Prompt Cache（模型侧）
```

**原则**：越靠近用户越快；越靠近源越准；每层都要有失效策略。

---

## 2. 可缓存内容

| 内容 | 层 | TTL | 失效 |
|---|---|---|---|
| 静态资源 | CDN | 长 | 版本 |
| 权限 | 本地+Redis | 10min | 角色变更 |
| Agent 配置 | Redis | 5min | 更新删 key |
| 模型配置 | 本地 | 1min | 更新广播 |
| Skill 元数据 | Redis | 10min | 版本变更 |
| 工具清单 | Redis | 5min | MCP 变更 |
| 配额桶 | Redis | — | Lua 原子 |
| 检索结果 | Redis | 1–10min | 数据变更 |
| Embedding | Redis/DB | 长 | 文档变更 |
| 会话摘要 | Redis | 会话级 | 新消息 |
| LLM 响应 | Redis/语义缓存 | 短 | 版本/租户 |
| 产物/大结果 | OSS | 长 | 会话删除 |

---

## 3. 缓存键设计

```text
t:{tenant}:{domain}:{version}:{hash}
```

**必须包含**
- 租户（隔离）。
- 版本（配置/模型/Prompt/Skill）。
- 内容哈希（输入/参数/工具集）。
- 权限范围（用户/角色）用于个性化缓存。

**禁止**：只用用户输入做 key（跨用户串数据）；忽略模型/版本（旧结果）。

---

## 4. 失效策略

| 策略 | 说明 | 适用 |
|---|---|---|
| TTL | 到期失效 | 配置/元数据 |
| 写后删 | 更新删 key | Agent/模型 |
| 版本号 | key 带版本 | Prompt/Skill |
| 事件驱动 | 发布失效消息 | 多实例 |
| 主动刷新 | 定时预热 | 热点 |
| stale-while-revalidate | 先旧后新 | 列表/配置 |

**多实例**：本地缓存通过 Redis Pub/Sub 广播失效；未收到也有 TTL 兜底。

---

## 5. Prompt Cache

Provider 侧前缀缓存：

- 固定顺序：策略 → Agent → 模板 → 工具 → 数据 → 历史 → 输入。
- 避免时间戳/随机 ID 在系统提示词。
- 工具定义排序稳定。
- JSON 规范化。
- 记录 `cached_tokens` 与命中率。

**收益**：输入成本 -50~90%（视 Provider）；首 token 更快。
**限制**：不同 Provider 规则不同；缓存 TTL 短；变更前缀即失效。

## 6. 语义缓存（高风险）

```
用户问题 → embedding → 相似检索
→ 相似度 ≥ 阈值 且 同租户/同Agent/同权限
→ 返回缓存答案；否则正常调用
```

**风险**
- 语义相似但答案不同（数字/时间/个体）。
- 跨租户/跨用户泄露。
- 数据过期。
- 缓存污染/注入。

**护栏**
- 只对「低风险、稳定事实」启用。
- 严格租户/Agent/权限隔离。
- 阈值高 + 人工抽检。
- 带 TTL；敏感数据不缓存。
- 命中后仍做安全/格式校验。

---

## 7. 工具/检索缓存

| 类型 | key | TTL | 注意 |
|---|---|---|---|
| 工具结果 | tenant+tool+args+auth scope | 短 | 权限/数据新鲜度 |
| 检索 | tenant+query+index version | 短 | 文档变更 |
| Embedding | model+chunk hash | 长 | 模型变更 |
| 配置 | tenant+resource+version | 中 | 写后删 |

**原则**：带权限的缓存必须把权限范围放进 key；否则会串数据。

---

## 8. 缓存问题与对策

| 问题 | 现象 | 对策 |
|---|---|---|
| 击穿 | 热点 key 失效，DB 被打爆 | 互斥重建/singleflight |
| 穿透 | 查不存在的数据 | 空值缓存/布隆过滤器 |
| 雪崩 | 大量 key 同时过期 | TTL 抖动/多级缓存 |
| 热 key | 单 key QPS 高 | 分片/本地缓存 |
| 脏数据 | 更新后读到旧值 | 写后删/版本/事件 |
| 串租户 | 看到别人数据 | key 带租户/权限 |
| 缓存污染 | 恶意内容进入缓存 | 校验/隔离/不缓存敏感 |

---

## 9. 复用（非缓存）

| 复用 | 说明 |
|---|---|
| Prompt 模板 | 版本化复用 |
| Skill 包 | 多 Agent 共享 |
| 工具定义 | 注册表复用 |
| 计划模板 | 多 Agent 复用 |
| 产物 | 会话内复用 |
| 附件 | 多消息引用 |
| 沙箱 | 会话复用/预热池 |

**区别**：缓存是「相同输入走捷径」；复用是「资产/结果被多次使用」。

---

## 10. 指标

| 指标 | 说明 |
|---|---|
| 命中率 | 按层/类型 |
| 节省成本 | 命中 × 单价 |
| 节省延迟 | 命中 vs 未命中 |
| 脏数据率 | 抽检/回滚 |
| 串租户 | 0 |
| 击穿/雪崩次数 | 稳定性 |

## 11. 优化 Playbook

| 优化 | 收益 | 成本 | 风险 | 优先级 |
|---|---|---|---|---|
| 权限/配置缓存 | 延迟 - | 低 | 低 | P0 |
| Prompt 前缀缓存 | 成本 -10~40% | 低 | 低 | P0 |
| 检索结果缓存 | 成本/延迟 - | 低 | 中 | P1 |
| Embedding 缓存 | 成本 - | 低 | 低 | P1 |
| 语义缓存 | 成本/延迟 - | 高 | 高 | P2 |
| 多级缓存 | 延迟 - | 中 | 中 | P1 |
| 缓存预热 | 延迟 - | 中 | 低 | P2 |

---

## 12. 验收标准

- [ ] 每类缓存有 key/TTL/失效策略。
- [ ] key 带租户/权限/版本。
- [ ] 多实例失效可广播。
- [ ] Prompt 缓存命中率可观测。
- [ ] 语义缓存有严格护栏（或暂不启用）。
- [ ] 击穿/穿透/雪崩有防护。
- [ ] 缓存不泄露跨租户/跨用户数据。
- [ ] 命中率与节省可量化。
