# 60 性能、延迟与吞吐优化

## 1. 端到端延迟预算

```
Client ─ 网络 ─ Gateway ─ Auth ─ API ─ Lock/配额
→ Context build ─ Retrieval ─ LLM TTFT ─ Stream
→ Tool calls ─ Persist ─ SSE ─ Render
```

| 阶段 | 预算（P95） | 优化点 |
|---|---|---|
| 网络/网关 | 50ms | CDN/就近接入 |
| Auth | 20ms | 缓存/本地校验 |
| 会话锁/配额 | 20ms | Redis Lua/本地 |
| 上下文组装 | 100ms | 缓存/并行 |
| 检索 | 300ms | 索引/重排/缓存 |
| LLM TTFT | 1.5–2.5s | 模型/区域/流式 |
| 工具 | 按工具 | 并行/超时 |
| 持久化 | 50ms | 批量/异步 |
| SSE/渲染 | 100ms | 合并/增量 |

**原则**：先优化「用户感知」——首 token；再优化总时长；最后优化吞吐。

---

## 2. 瓶颈定位树

```
首 token 慢？
├─ 排队/锁 → 锁粒度/并发
├─ 配额 → 池/模式
├─ 上下文太大 → 压缩/缓存
├─ 检索慢 → 索引/缓存/并行
├─ 模型 TTFT 慢 → 区域/模型/供应商
└─ 网络/代理 → SSE 缓冲/长连接

完整响应慢？
├─ 输出太长 → max_tokens/格式
├─ 工具多/串行 → 并行/裁剪
├─ 多轮循环 → 预算/提示/工具选择
└─ 持久化慢 → 批量/异步

吞吐上不去？
├─ DB 写放大 → 批量/分区
├─ Redis 热 key → 分片/本地
├─ SSE 内存 → 独立网关/背压
├─ 模型 TPM → 多供应商/配额
└─ 沙箱供给 → 预热/扩容
```

## 3. SSE 优化

| 优化 | 说明 | 收益 |
|---|---|---|
| 事件合并 | 30–60ms 批量 token | 减少写/渲染 |
| 关闭代理缓冲 | `X-Accel-Buffering: no` | 首 token 不被卡 |
| 心跳 | 15s `: ping` | 连接稳定 |
| 压缩 | gzip/br（文本） | 带宽 |
| 背压 | 慢消费者合并/丢弃 | 内存 |
| 独立网关 | 不与 API 混部 | 连接数 |
| 连接复用 | HTTP/2/keep-alive | 握手 |
| 断线续传 | ring buffer | 体验 |

**注意**：gzip 可能增加 CPU；SSE 小包压缩收益有限，需实测。

## 4. DB 优化

| 问题 | 优化 |
|---|---|
| 每 token 写库 | 只在 msg_end 写最终内容 |
| 单条插入 | 批量 50–100 条 |
| 事务过大 | 拆分/异步 |
| 慢查询 | 索引/覆盖索引/游标分页 |
| 大表 | 分区/归档 |
| 读多 | 只读副本/缓存 |
| 连接耗尽 | 池化/限制/异步 |
| 锁竞争 | 短事务/乐观锁 |

**目标**：单轮对话 DB 写入 ≤5 次；列表 P95 ≤500ms。

---

## 5. Redis 优化

| 问题 | 优化 |
|---|---|
| 热 key | 分片/本地缓存 |
| 多次往返 | pipeline/Lua |
| 大 key | 拆分/压缩 |
| Stream 太长 | MAXLEN/TTL |
| Pub/Sub 丢消息 | 配合 Stream |
| 内存高 | 淘汰策略/过期 |

**SSE**：`XADD` 批量；`MAXLEN ~ 2000`；发布与写入分离。

## 6. 模型延迟优化

| 优化 | 说明 | 风险 |
|---|---|---|
| 模型分级 | 小模型优先 | 质量 |
| 区域就近 | 同地域 endpoint | 成本 |
| 流式 | 首 token 快 | — |
| 限制输出 | max_tokens/格式 | 完整性 |
| 减少轮次 | 工具选择/提示 | 质量 |
| 并行工具 | 只读并行 | 一致性 |
| 连接复用 | HTTP/2/keep-alive | — |
| 预填/缓存 | Prompt cache | 前缀稳定 |
| 备用模型 | 故障切换 | 质量差异 |

## 7. 并行化

| 可并行 | 说明 |
|---|---|
| 检索 | 多源并行 |
| 工具 | 只读工具并行 |
| 子 Agent | 无依赖任务并行 |
| 附件解析 | 多文件并行 |
| 上下文加载 | Agent/Skill/模型配置并行 |
| 持久化 | 消息/用量/审计异步 |

**原则**：并行只读；写操作串行；有依赖用 DAG。

---

## 8. 前端优化

- 首屏：路由懒加载、骨架屏、关键资源预加载。
- 流式：批量渲染（30–60ms）、Markdown 增量、代码高亮延后。
- 长列表：虚拟滚动。
- 请求：去重、缓存、取消。
- 弱网：重连、草稿、离线提示。
- 体积：按路由分包、剔除大依赖。

---

## 9. 过载保护

| 机制 | 说明 |
|---|---|
| 入口限流 | IP/用户/租户 |
| 优先级 | 交互 > 后台 |
| 准入 | 配额/队列/沙箱 |
| 背压 | 合并/丢弃旧 token |
| 熔断 | 依赖错误率高 |
| 降级 | 关非核心 |
| 排队 | 429 + Retry-After |

**原则**：明确拒绝 > 全站雪崩。

## 10. 压测方法

```
基线 → 阶梯加压 → 找拐点 → 定位瓶颈 → 优化 → 回归
```

| 场景 | 目标 |
|---|---|
| 200 并发对话 | 错误<1%，首 token P95≤3s |
| 5k SSE | 断连<0.1% |
| 100 并发沙箱 | 创建 P95≤10s |
| 1万条/秒事件 | 不丢 |
| 1亿消息 | 分页 P95≤500ms |

**记录**：版本、配置、数据量、瓶颈、改进。

## 11. 优化 Playbook

| 优化 | 收益 | 成本 | 风险 | 优先级 |
|---|---|---|---|---|
| SSE 合并/防缓冲 | 首 token/吞吐 + | 低 | 低 | P0 |
| DB 批量/索引 | 延迟/稳定 + | 低 | 低 | P0 |
| 上下文压缩 | 首 token + | 中 | 中 | P0 |
| 模型分级/就近 | 延迟/成本 + | 中 | 中 | P1 |
| 并行工具/检索 | 总时长 - | 中 | 中 | P1 |
| 独立 SSE 网关 | 吞吐 + | 中 | 低 | P1 |
| 预取/预热 | 延迟 - | 中 | 低 | P2 |
