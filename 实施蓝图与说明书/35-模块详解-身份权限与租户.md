# 35 模块详解：身份、权限与租户

## 1. 职责与边界

**负责**
- 身份认证：OIDC SSO、飞书 OAuth、API Key、A2A、Bridge。
- 会话：业务 JWT、refresh、登出、吊销。
- 授权：RBAC、资源 ACL、数据范围。
- 租户：解析、传播、隔离。
- 审计：登录、权限、密钥、高危操作。

**不负责**：Agent/Skill/会话业务规则；模型密钥（属 Model 模块）。

## 3. 认证模式

### 3.1 企业 OIDC SSO（默认）

```
GET /auth/sso/config → 前端拿 base_url/client_id/redirect_uri
→ 生成 state + nonce（sessionStorage）
→ 跳 {sso}/oidc/auth?response_type=code&...
→ 回调 /auth/callback?code&state
→ 后端校验 state/nonce → code 换 token → userinfo
→ upsert sys_user → 签发业务 JWT + refresh
→ GET /auth/me/permissions
```

**配置**
```yaml
sso:
  base_url: https://sso.example.com
  client_id: cloud-agent
  client_secret: ${SSO_CLIENT_SECRET}
  redirect_uri: https://agent.example.com/auth/callback
  scopes: openid profile email phone
  state_ttl: 600
```

**JWT claims**
```json
{
  "sub": "u_123",
  "tenant_id": "t_1",
  "roles": ["content_creator"],
  "permissions": ["agent:view", "agent:chat"],
  "jti": "j_abc",
  "iat": 1760000000,
  "exp": 1760001800,
  "iss": "cloud-agent",
  "aud": "web"
}
```

### 3.2 刷新与登出

- access 15–30min；refresh 7–30d；Redis 存 `sso:refresh:{jti}`。
- 刷新：`POST /auth/refresh`，读 refresh → 校验 → 新 access（可轮换 refresh）。
- 并发 401：前端只触发一次刷新，其余请求等待。
- 登出：删 Redis 会话键；旧 JWT 因会话不存在而拒绝。
- 禁用用户/角色变更：删权限缓存 + 拉黑 jti。

### 3.3 API Key（系统对系统）

```
Authorization: XPD-HMAC-SHA256 app_id=..., timestamp=..., nonce=..., signature=...
signature = HMAC-SHA256(secret, app_id\ntimestamp\nnonce\nmethod\npath\nbody_sha256)
```

校验：app_id 存在/启用 → 时间窗 ±5min → nonce 未用 → 签名 → scope → allowed_agents → 审计。
Scope：`blocking`、`sessions`、`agents`、`a2a`、`access_token`。
创建时一次性返回 secret；列表永不返回；支持轮换/禁用/删除。

### 3.4 Bridge（嵌入）

- 宿主 `postMessage` 下发短期 token/spaceCode/welcomeContext。
- 子应用校验 origin；token 只存内存/sessionStorage。
- 401 → 发 `sdk:token-expired` → 宿主回 `sdk:token-update` → 重试。
- 15s 超时 → 提示重新登录。

### 3.5 A2A / 服务间

- A2A：Bearer token（按端点配置）；Agent Card 公开。
- 内部回调：HMAC + 时间窗 + nonce + task_id。
- 服务间：mTLS 或服务 token（短期）。

## 4. 授权模型

### 4.1 RBAC

```python
@router.get("/agents")
async def list_agents(user=Depends(require_permission("agent:view"))): ...
```

- 前端隐藏按钮只是体验；后端必须校验。
- 权限码 `资源:动作`；新增归入 `group_code`。
- 角色变更清缓存；缓存 TTL 10min 兜底。

### 4.2 资源 ACL

| 动作 | owner | collaborator | public | 管理员 |
|---|---|---|---|---|
| view | ✅ | ✅ | ✅ | ✅ |
| edit | ✅ | ✅ | ❌ | ✅ |
| delete | ✅ | ❌ | ❌ | ✅ |
| manage collaborators | ✅ | ❌ | ❌ | ✅ |

判定顺序：管理员 → owner → collaborator → public → 404/403。
协作者幂等添加；软删后再添加复用；转移 owner 需目标有创建权限。

### 4.3 数据范围

| 角色 | 会话/用量可见 |
|---|---|
| super_admin/content_admin | 全部 |
| content_creator | 自己 + 协作 |
| user | 自己 |

越权返回 403；无权资源可返回 404 防枚举。

## 5. 租户隔离

```
Gateway → 解析 tenant（域名/Token claim/Header）
→ TenantContext(tenant_id) 注入请求
→ Repository 强制 tenant_id
→ Redis key / OSS prefix / 日志 / 指标带 tenant
```

**规则**
- 禁止从请求 body/query 接收 `tenant_id`（除超管跨租户操作）。
- 所有唯一性校验带租户。
- 跨租户测试进入 CI（两个租户互访 → 0 成功）。
- 多租户级别：L1 共享表 → L2 schema → L3 独立库 → L4 独立部署。

## 7. 失败与安全

| 场景 | 行为 |
|---|---|
| SSO 不可用 | 已有会话继续；新登录提示 |
| JWT 过期 | 401 → 刷新 → 重放；失败跳 SSO |
| refresh 失效 | 清除本地 token → SSO |
| 越权 | 403/404；审计 |
| API Key 错签/重放 | 401；告警 |
| 角色变更 | 清缓存；下次请求生效 |
| 密钥泄露 | 轮换 + 撤销会话 + 排查 |

**安全**
- JWT 固定算法；校验 iss/aud/exp；禁止 none。
- state/nonce 一次性；回调白名单；建议 PKCE。
- 密码/密钥不落日志；API Key 只存哈希/密文。
- 登录失败限流；异常登录告警。

## 10. 代码骨架

```python
# core/security.py
async def get_current_user(token: str = Depends(bearer)) -> UserContext:
    claims = decode_jwt(token)
    if not await session_alive(claims["jti"]):
        raise Unauthenticated()
    return UserContext(**claims)

def require_permission(code: str):
    async def dep(user: UserContext = Depends(get_current_user)):
        if code not in user.permissions and not user.is_super_admin:
            raise Forbidden(code)
        return user
    return dep

async def require_resource_access(resource_type, resource_id, action, user):
    if user.is_admin: return
    acl = await acl_repo.get(resource_type, resource_id, user.user_id)
    if not acl.allows(action): raise NotFound()
```
