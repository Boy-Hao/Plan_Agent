# 37 模块详解：会话与运行时

## 1. 职责与边界

**Conversation（控制面）**
- 会话创建/列表/重命名/删除。
- 消息持久化、历史分页。
- 权限/归属/数据范围。
- 活跃轮指针、取消入口。

**Runtime（数据面）**
- 上下文组装（提示词/历史/变量/引用/附件/技能）。
- 模型调用（流式/工具/多轮）。
- 工具/Skill/MCP/子 Agent 执行。
- SSE 事件、调用链、用量。

**不负责**：模型配置（Model）、Skill 包解析（Skill）、沙箱实例（Execution）。

## 2. 数据模型

| 表 | 关键字段 |
|---|---|
| `session` | session_id, tenant_id, agent_id, user_id, biz_id, name, source, source_name, last_active_time, last_message_summary, total_tokens, is_deleted |
| `message` | message_id, tenant_id, session_id, role, content, metadata(JSON), status, seq, create_time |
| `turn` | turn_id, session_id, message_id, status, model, started_at, ended_at, error_code, client_message_id |

| `task_plan` | id, session_id, message_id, plan(JSON), version, status |
| `sub_agent_task` | id, parent_session_id, child_session_id, task_run_id, plan(JSON), status |
| `external_context` | id, session_id, context_key, content, active, expire_time |
| `session_attachment` | id, session_id, message_id, file_id |
| `trace` | trace_id, turn_id, root_node, status, duration_ms |

**唯一键**：`(tenant_id, session_id, client_message_id)` 防重复提交；`(message_id, seq)` 保证顺序。

## 3. Turn 状态机

```
received → queued → running → tool_wait → running → completed
                                  │
                                  ├→ cancelled
                                  └→ failed
```

| 状态 | 进入条件 | 退出 |
|---|---|---|
| received | 收到请求 | 获取锁/配额 |
| queued | 等待模型/配额 | 准入 |
| running | 开始 LLM | 完成/工具/取消 |
| tool_wait | 等待工具 | 工具结束/超时 |
| completed | 正常结束 | 终态 |
| cancelled | 用户取消/超时 | 终态 |
| failed | 不可恢复错误 | 终态 |

**规则**：终态不可变；每次变更写 `turn_event`；`msg_end` 必发。

## 4. SSE 协议

### 4.1 端点

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/conversations/{id}/chat` | 发送并流式返回 |

| GET | `/conversations/{id}/task-plan` | 任务计划 |
| GET | `/conversations/{id}/tool-results` | 工具轨迹 |

### 4.2 事件

```json
{ "id": "123", "event": "token",
  "data": { "event_id":"evt_x", "turn_id":"turn_x", "message_id":"msg_x",
            "seq":42, "version":1, "delta":"你好" } }
```

| 事件 | 关键字段 |
|---|---|
| `msg_start` | message_id, model |
| `token` | delta |
| `thinking` | delta |
| `tool_call_start` | tool_call_id, name, args_summary |
| `tool_call_end` | status, duration_ms, result_summary |
| `artifact` | artifact_id, type, url |
| `task_plan_updated` | plan, version |
| `sub_agent_progress` | child_session_id, status |
| `sub_agent_task_plan_updated` | plan |
| `msg_end` | status, usage |
| `error` | code, message, retryable |

### 4.3 续传

```
1. GET /active-turn → message_id/status
2. GET /live?message_id=... + Last-Event-ID
3. 订阅 sse:live:{mid}
4. 重放 sse:log:{mid}（从 last id 之后）
5. tail 到 msg_end
6. 若 truncated → 拉消息详情补齐
```

**Redis**：`sse:log:{mid}` Stream（MAXLEN）、`sse:live:{mid}` Pub/Sub、`session:active_turn:{sid}` Hash。

## 5. 上下文组装

### 5.1 顺序

1. 平台安全策略（不可覆盖）
2. Agent 系统提示词
3. 业务模板（biz_id）
4. 引用源（用户选择）
5. 附件内容/摘要
6. 历史（窗口 + 摘要）
7. 当前输入

### 5.2 预算

| 内容 | 策略 |
|---|---|
| 系统提示词 | 固定；超长警告 |
| 历史 | token 窗口 + 摘要 |
| 引用源 | 条数/字符上限 |
| 附件 | 解析文本/摘要；图片多模态 |
| 工具结果 | 单条/总上限；大结果落 OSS |

### 5.3 变量

- `sys_*` / `agt_*` / `usr_*`，优先级按业务（默认 user > agent > system）。
- 密钥只以占位符进入 prompt；真实值在工具执行时注入。
- 日志/调用链只记录变量名。

## 6. 工具执行

```
模型返回 tool_calls
→ 校验工具白名单/参数 Schema/权限/配额
→ 记录 tool_call(pending, 幂等键)
→ 执行（并发只读/串行写）
→ 结果脱敏/截断
→ 记录 done + 回填模型
```

**超时**：工具级 30s（可配）；失败返回结构化错误，不中断整轮。
**高危**：删除/发送/提 MR 需二次确认或审批。
**幂等**：`(turn_id, tool_call_id)`；外部副作用用业务幂等键。

## 7. MCP

- 每个 Agent 多个 MCP Server；`tool_exposure=all|selected`。
- Header 只存变量引用模板。
- 测试：草稿/已保存；返回工具列表/延迟/错误。
- 不可用：跳过并提示，不阻塞整轮。

## 8. 子 Agent 与任务计划

```json
{
  "plan_id": "plan_x", "version": 2, "status": "in_progress",
  "tasks": [
    {"id":"t1","title":"查 BOM","status":"done","depends_on":[]},
    {"id":"t2","title":"校验","status":"running","depends_on":["t1"]}
  ]
}
```

- 子 Agent 独立 `child_session_id`，独立上下文。
- 父只收摘要 + 产物引用 + 关键结果。
- 预算：每任务/总 token、时长、工具数。
- 失败：重试/跳过/升级；循环依赖拒绝。
- 事件：`task_plan_updated`、`sub_agent_progress`。

## 10. 失败与降级

| 失败 | 行为 |
|---|---|
| 锁冲突 | 409/排队 |
| 配额拒绝 | 429 + reset |
| 模型超时 | 重试/备用/报错 |
| 工具超时 | 返回超时给模型 |
| 持久化失败 | 重试/ring buffer 恢复 |
| Redis 故障 | SSE 降级；锁降级 DB |
| 进程崩溃 | turn failed；重启扫描 |
| 客户端断开 | 保留 buffer 5–10min |

## 11. 可观测

- `request_id → session_id → turn_id → message_id → llm_call/tool_call`。
- 阶段耗时：排队/上下文/LLM/工具/持久化。
- 指标：首 token、完整延迟、错误率、工具成功率、取消率、续传成功率。
- Trace：树状调用链；大内容按需加载；脱敏。

## 13. 代码骨架

```python
async def chat(session_id, req, user):
    session = await repo.get_or_404(session_id, user.tenant_id)
    assert_access(session, user, "agent:chat")
    turn = await turns.create(session, req.client_message_id)
    lock = await locks.acquire(session_id, turn.turn_id, ttl=30)
    try:
        async for ev in runtime.run(session, turn, req):
            await sse.publish(turn.message_id, ev)
        await turns.complete(turn)
    except Cancelled:
        await turns.cancel(turn)
    finally:
        await locks.release(lock)
```

## 14. 测试

- 并发同会话 → 只有一个活跃轮。
- 取消 2s 内传播；`msg_end(cancelled)`。
- 断线 30s 重连不丢/不重。
- 刷新恢复历史。
- 工具超时/失败不崩。
- 子 Agent 预算/超时/循环。
- 事件顺序/去重/版本。
