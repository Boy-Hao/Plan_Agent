# 39 模块详解：沙箱与执行

## 1. 职责与边界

**负责**
- 沙箱配置（domain/template/api_key/TTL/env/Git/LLM 代理）。
- 沙箱生命周期（创建/复用/暂停/恢复/销毁/回收）。
- 沙箱任务（shell/coding/generic、CLI、事件/日志、取消）。
- Git 认证（caller/platform、租约、MR）。
- 安全隔离、容量、成本。

**不负责**：Agent 决策（Runtime）、模型调用（Model Gateway）、文件业务（Files）。

## 3. 生命周期

```
request → check config/quota/concurrency
→ lazy: create on first use / prewarm: from pool
→ provisioning → running
→ idle > pause_after → paused
→ paused > delete_after → deleted
→ reset/timeout/error → kill
```

状态：`creating → running → paused → deleting → deleted`；失败 `failed`。
**幂等**：同会话重复请求返回同沙箱；重置可预览影响。
**回收**：定时 reconcile 清理孤儿；管理端批量 kill。

---

## 4. 模式

### 4.1 生命周期模式

| 模式 | 行为 | 适用 | 成本 |
|---|---|---|---|
| `ttl` | 到 TTL 直接销毁 | 短任务 | 低 |
| `platform_idle` | 空闲暂停，暂停后销毁 | 交互式 | 中 |
| `never_timeout` | 不自动销毁（需显式） | 调试/长任务 | 高 |

### 4.2 创建策略

| 模式 | 行为 | 适用 |
|---|---|---|
| `lazy` | 首次使用创建 | 默认 |
| `prewarm` | 预热池取用 | 高并发/低延迟 |

### 4.3 共享模式

| 模式 | 行为 | 风险 |
|---|---|---|
| 独占 | 一会话一沙箱 | 成本高 |
| 共享池 | 多主体共享槽位 | 数据残留；需清理 |
| 只读 | 禁止写 | 分析/查询 |

### 4.4 Git 模式

| 模式 | 说明 |
|---|---|
| `caller` | 调用方传 token（短期） |
| `platform` | 平台编码账号签发项目 token |
| `fallback` | platform 失败回退 caller |
| MR `platform` | 平台创建 MR |
| MR `skill` | Skill 自行创建 |

## 5. per-run 环境变量

白名单（只允许）：

```
ANTHROPIC_API_KEY / ANTHROPIC_BASE_URL / ANTHROPIC_MODEL
OPENAI_API_KEY / OPENAI_BASE_URL / OPENAI_MODEL
GIT_URL / GIT_TOKEN / GIT_REPOS
```

规则：
- `GIT_URL` 必填；`GIT_TOKEN` caller 必填、platform 可选；
- 模型 key 可缺省，由平台默认模型补齐；
- `GIT_REPOS` JSON 数组，支持多仓独立 token；
- 空串不作为删除；
- 错误/日志只出现 key 名；
- 请求结束立即清理。

---

## 6. Git 租约

```
申请 → 校验项目白名单 → 生成/获取 token → 加密存租约
→ 注入沙箱 → 任务结束/超时 → 回收
```

- 租约 TTL（如 30min）；可手工回收。
- 平台账号 PAT 不直接给沙箱。
- 审计：谁/何时/哪个仓库/操作。
- 泄露：撤销租约 + 轮换。

---

## 7. LLM 代理

```
沙箱 → /api/v1/llm-proxy/{config_id}/{path}
→ 校验 config/路径前缀/Authorization
→ 转发 target + 内层路径（流式）
→ 记录用量/费用
```

| 情况 | 响应 |
|---|---|
| BASE_URL 未配置 | 404（功能关闭） |
| config 不存在/软删 | 404 |
| Authorization 缺失/非 Bearer | 401 |
| 路径未命中前缀 | 403 |

**安全**：域名白名单、禁 SSRF、只允许配置前缀、记录审计。

## 8. 任务模型

```json
{
  "session_id": "s1",
  "command": "pytest -q",
  "kind": "shell|coding|generic",
  "cli": "claude|codex|pi|",
  "access_mode": "write|read",
  "timeout_seconds": 600,
  "cwd": "/workspace",
  "progress_adapter": "pytest",
  "message_id": "m1",
  "sandbox_id": "sb1"
}
```

- 异步执行，返回 `task_id`。
- 事件：queued → started → output → progress → completed/failed/cancelled。
- 日志分页；大日志落 OSS。
- 取消幂等；超时 kill。
- 回调：`/sandbox-task-callbacks/{task_id}/report|complete`，签名校验。

## 9. 安全

| 层 | 控制 |
|---|---|
| 隔离 | microVM/gVisor；独立内核/命名空间 |
| 网络 | 默认拒绝；出站白名单；禁内网/元数据 |
| 文件 | 独立目录；只读根；任务后清理 |
| 凭证 | 短期租约；代理；不注入长期密钥 |
| 资源 | CPU/内存/磁盘/进程/时间限额 |
| 镜像 | 签名/扫描/固定 digest/最小化 |
| 行为 | 命令审计/异常检测/超限终止 |
| 演练 | 逃逸/提权/横向移动 |

**红线**：Docker 容器不作为多租户边界；沙箱节点不挂载宿主敏感目录；不访问 K8s API。

## 10. 容量与成本

```
沙箱并发 = 日任务数 × 平均时长 / 86400 × 峰值系数
节点数 = 并发 × 单沙箱资源 / 节点资源 / 0.7
预热池 = 峰值并发 × 10%–20%
```

- 模板瘦身/预拉取；空闲暂停；共享池；自动扩缩。
- 成本按用户/Agent/配置归因。
- 创建失败率 > 5% 告警。

## 12. 失败与降级

| 场景 | 行为 |
|---|---|
| 创建失败 | 重试 → 报错/降级只读工具 |

## 14. 代码骨架

```python
async def ensure_sandbox(session, cfg) -> Sandbox:
    binding = await repo.get_binding(session.id)
    if binding and binding.alive(): return binding.sandbox
    if cfg.creation_strategy == "prewarm":
        sb = await pool.acquire(cfg)
    else:
        sb = await provider.create(cfg)
    await repo.bind(session.id, sb.id, cfg.scope)
    return sb

async def run_task(task):
    sb = await ensure_sandbox(task.session, task.cfg)
    lease = await git.issue(task.user, task.cfg)
    try:
        async for ev in sb.exec(task.command, env=task.env, lease=lease):
            await events.publish(task.id, ev)
    finally:
        await git.release(lease)
```

## 15. 验收标准

- [ ] 沙箱无法访问宿主/内网/他人数据。
- [ ] 生命周期/暂停/回收正确。
- [ ] 任务可取消/超时/日志可查。
- [ ] Git 租约短 TTL、可回收、不落日志。
- [ ] LLM 代理白名单生效。
- [ ] 创建成功率 ≥99%，预热后 P95 ≤2s。
- [ ] 成本可归因。
