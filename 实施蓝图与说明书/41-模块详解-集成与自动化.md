# 41 模块详解：集成与自动化

## 1. 集成架构

```
Integration Service
  ├─ Feishu Adapter（WS/OAuth/Push/Event/Card）
  ├─ GitLab Adapter（Sync/OAuth/Coding/MR）
  ├─ A2A Adapter（Agent Card/Message Stream）
  ├─ Webhook Dispatcher（outbound）
  ├─ Scheduler（cron/once）
  └─ Data Page / Chart Adapter
```

**原则**：适配器隔离厂商 SDK；统一重试/超时/熔断/审计；外部故障不影响核心对话。

## 2. 飞书机器人

### 2.1 配置

| 字段 | 说明 |
|---|---|
| app_id/app_secret | 应用凭证（加密） |
| encrypt_key/verification_token | 事件校验 |
| enabled | 启停 |
| is_default/is_primary | 默认/主应用 |
| bot_chat_enabled | 允许 IM 对话 |
| agent_ids | 绑定 Agent |
| event_keys | 订阅事件 |

### 2.2 长连接

- WS 接收事件，避免公网回调。
- 多实例用分布式锁/租约保证单活跃连接。
- 断线重连/心跳/错误上报；状态写 Redis。
- 管理端可触发重连。

### 2.3 消息路由

```
消息 → 校验 → open_id → 绑定用户
→ 选择 Agent（配置/关键词/默认）
→ 创建/复用会话 → Runtime 流式
→ 增量更新卡片/发送
```

- 未绑定 → 引导 bind_nonce。
- 无 Agent → 提示管理员。
- 群聊/私聊/@ 策略可配。

### 2.4 模式

| 模式 | 说明 |
|---|---|
| 私聊 | 1:1 对话 |
| 群聊 @ | 群里@机器人 |
| 卡片流式 | 增量更新卡片 |
| 文本 | 纯文本回复 |
| 关闭对话 | 只推送/不对话 |

## 3. 飞书 OAuth

```
Web: POST /feishu/oauth/prepare (Bearer) → ticket + authorize_url
→ /authorize → 302 飞书 → callback → state 消费 → token 加密落库
Feishu 内嵌: prompt_id → owner → 302
```

- 多应用 primary/default；切换 revoke 旧 token。
- token 加密；过期刷新；失败提示。
- 管理端可查看/撤销；统计授权率。

---

## 4. 飞书事件订阅

| 概念 | 说明 |
|---|---|
| 能力目录 | 可订阅事件全集（DB 优先） |
| Agent 白名单 | 哪些 Agent 可用 |
| 用户订阅 | H5 勾选 + 目的 |
| 事件处理 | 匹配订阅 → 触发 Agent/通知 |

**保护**：事件被 Agent 绑定时禁止删除；解绑后删。
**事件**：会议开始/结束、纪要、日历、文档评论。

---

## 5. 飞书推送

```
应用 → 模板/卡片 → 接收人（部门/用户/组）
→ 解析 open_id（email/mobile 兜底）→ 预览
→ 分批发送（≤200）→ 记录 → 进度/阅读 → 撤回
```

- 过滤器：邮箱规则。
- 发送日志/失败重试/批次。
- 大范围发送二次确认；频率限制。
- 卡片 JSON 不落库（仅本次）。

## 6. GitLab

### 6.1 Skill 同步

- 全局配置：base_url/project/branch/directory/token（加密）。
- 预览：新增/更新/跳过/冲突。
- 执行：递归扫描，每个含 SKILL.md 目录 = Skill。
- 结果明细/重试/上次同步。

### 6.2 OAuth

- 用户授权 → code 换 token → 加密。
- 状态/撤销/统计。
- 白名单端点用 state nonce。

### 6.3 编码账号

- 平台 PAT；验证身份/到期/项目访问。
- 项目白名单；租约 TTL；回收。
- 不暴露主 PAT 给沙箱。

### 6.4 MR

- 沙箱提交 → 平台创建 MR → 记录链接/状态。
- 失败重试；权限/审计。

## 7. A2A

| 能力 | 说明 |
|---|---|
| Agent Card | `/.well-known/agent-card.json` |
| Message Stream | `POST /iron/message:stream` |
| 认证 | Bearer（按端点） |
| 多端点 | public_base_url + path_prefix |

- 平台 Agent 被外部调用；平台调用外部 Agent。
- Token 加密/轮换/限流。
- Agent Card 不暴露内部地址/密钥。

---

## 8. Webhook

- 注册 URL/事件/签名密钥。
- 事件：会话完成/任务完成/审批结果。
- 至少一次、指数退避、死信、手工重试。
- HMAC + timestamp；HTTPS only；防 SSRF。

---

## 9. 定时调度

| 类型 | owner | 说明 |
|---|---|---|
| 用户任务 | user | 用户创建 |
| Agent 自调度 | agent | Agent 创建 |

- cron/once；时区统一；错过补跑策略。
- 并发限制；失败重试；执行日志。
- 暂停/恢复/手动触发/删除。

---

## 10. 数据网页

- 上传 HTML/ZIP → `page_key`。
- 版本/回滚/下架（410）。
- `/d/{page_key}/` 静态；相对路径。
- 数据通过 URL（gzip+base64url）。
- 安全：CSP/沙箱/禁止访问平台 API。

---

## 11. 图表/BI

- 取数：视图详情 → 真实数据。
- 发布：BI API → chartId → 拼接查看链接。
- 状态：draft/published；失败结构化返回。
- 权限：按用户/项目；不缓存敏感数据。

## 13. 失败与安全

| 场景 | 行为 |
|---|---|
| 飞书 WS 断 | 自动重连；Web 入口可用 |
| 飞书 token 过期 | 刷新；失败提示 |
| 推送部分失败 | 记录批次；重试失败项 |
| GitLab 5xx | 重试/熔断 |
| 回调签名错误 | 401 |
| A2A token 无效 | 401 |
| Webhook 超时 | 重试/死信 |

**安全**：密钥加密；回调验签；防 SSRF；权限/审计；限流。
