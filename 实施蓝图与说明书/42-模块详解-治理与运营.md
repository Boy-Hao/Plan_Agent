# 42 模块详解：治理与运营

## 1. 范围

| 子域 | 能力 |
|---|---|
| 审计 | 操作日志、登录、权限、密钥、导出 |
| 权限审计 | 申请、审批、授权、证据、配置变更 |
| 用量 | token/费用、按用户/Agent/模型/会话 |
| 反馈 | 点赞/点踩、原因、汇总、上下文 |
| 系统参数 | 分组配置、版本、待生效、Pod 状态 |
| 通知 | SSE、未读、已读、类型 |
| OSS 治理 | 盘点、孤儿、回收、容量、门禁 |

---

## 2. 审计

### 2.1 事件模型

```json
{
  "audit_id": "a1",
  "tenant_id": "t1",
  "user_id": "u1",
  "action": "agent.updated",
  "resource_type": "agent",
  "resource_id": "agt1",
  "before": {"name": "旧"},
  "after": {"name": "新"},
  "result": "success",
  "ip": "10.0.0.1",
  "ua": "...",
  "request_id": "req1",
  "create_time": "..."
}
```

### 2.2 范围

- 登录/登出/失败；
- 角色/权限变更；
- 密钥创建/轮换/禁用；
- 模型/配额变更；
- Agent/Skill 增删改；
- 沙箱/文件回收；
- 导出/下载。

### 2.3 模式

| 模式 | 说明 |
|---|---|
| 同步写 | 强一致，慢 |
| 异步写 | 走 outbox，快 |
| 全量 | 所有操作 |
| 采样 | 高频只读 |
| WORM | 合规不可改 |
| 归档 | 冷存储 |

**建议**：高危同步/异步 outbox；只读采样；审计保留 ≥1 年。

## 3. 权限审计

### 3.1 流程

```
申请（权限点/理由/期限/证据）
→ 审批（单人/双人）
→ 授予临时 grant（到期）
→ 使用（记录）
→ 到期/释放 → 证据归档
```

### 3.2 组成

| 模块 | 说明 |
|---|---|
| eligible-permissions | 可申请权限点 |
| applications | 申请/撤回/查询 |
| grants | 授权/释放/撤销 |
| policies | 哪些需审计/审批人/有效期 |
| config-changes | 审计开关变更（双人审批） |
| evidence | 操作/审批/使用记录 |
| exports | 脱敏导出 |

### 3.3 模式

| 模式 | 说明 | 适用 |
|---|---|---|
| 关闭 | 不启用 | 首版 |
| 记录 | 只记录不审批 | P1 |
| 单人审批 | 一人批 | P2 |
| 双人审批 | 两人批 | 高危 |
| 限期 | 到期自动回收 | 默认 |
| 长期 | 需定期复核 | 特殊 |

## 5. 反馈

- 点赞/点踩/原因（≤256）；
- 同一用户重复提交 update；
- 撤回软删；
- 管理端明细/汇总/上下文（前后消息）；
- Agent 下拉只显示有权限的。

**指标**：点赞率、差评 TopN、Agent 对比、版本对比。

## 10. 失败与安全

| 场景 | 行为 |
|---|---|
| 审计写入失败 | 重试/本地缓冲；高危阻断 |
| 导出失败 | 重试/通知 |
| 审批人缺失 | 转交/超时升级 |
| 授权过期 | 自动失效 |
| 用量丢失 | 对账/补录 |
| 通知断连 | 重连/补齐 |
| 盘点失败 | 重试/告警 |

**安全**：审计防篡改；导出脱敏/水印；权限最小；操作留痕。

## 11. 测试

- 审计覆盖高危操作。
- 权限审计申请/审批/授权/到期/回收。
- 用量准确/对账。
- 反馈 upsert/撤回/汇总。
- 系统参数版本/待生效/回滚。
- 通知实时/未读/多端。
- OSS 盘点/孤儿/回收。

## 12. 验收标准

- [ ] 高危操作 100% 审计，可导出。
- [ ] 权限审计可按策略开关，双人审批可用。
- [ ] 用量可按用户/Agent/模型/时间查询。
- [ ] 反馈可闭环到 Agent 改进。
- [ ] 系统参数可版本化/回滚。
- [ ] 通知实时/未读准确。
- [ ] OSS 治理可发现/回收/门禁。
