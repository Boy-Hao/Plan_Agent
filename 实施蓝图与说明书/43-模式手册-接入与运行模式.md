# 43 模式手册：接入与运行模式

> 本手册按「模式」组织：每种模式说明**什么时候用、怎么配、怎么跑、坏了怎么办、怎么验收**。

---

## 1. 接入模式

### M1 Web 工作台

| 项 | 内容 |
|---|---|
| 适用 | 主要用户 |
| 入口 | `/`、`/agents`、`/chat` |
| 认证 | SSO + JWT |
| 流式 | SSE |
| 配置 | `VITE_API_BASE`、SSO |
| 失败 | 401 → 刷新 → SSO |
| 验收 | 登录→对话→历史→反馈 |

### M2 H5（移动/飞书内嵌）

| 项 | 内容 |
|---|---|
| 适用 | 手机/飞书工作台 |
| 入口 | `/H5/skills`、`/H5/inbox`、`/H5/event-subs` |
| 认证 | SSO/飞书 OAuth |
| 特点 | 轻量、单列、触控 |
| 失败 | 授权过期 → 重新授权 |
| 验收 | 移动端可完成核心任务 |

### M3 飞书机器人

| 项 | 内容 |
|---|---|
| 适用 | IM 内使用 |
| 入口 | 私聊/群聊 @ |
| 认证 | 飞书 open_id 绑定 |
| 流式 | 卡片增量/消息 |
| 配置 | app_id/secret/WS/agent_ids |
| 失败 | WS 断 → 重连；token 过期 → 授权 |
| 验收 | 私聊提问→流式回复→可继续 |

### M4 A2A

| 项 | 内容 |
|---|---|
| 适用 | Agent 间/跨系统 |
| 入口 | `/iron/.well-known/agent-card.json`、`/iron/message:stream` |
| 认证 | Bearer |
| 流式 | SSE/流 |
| 配置 | public_base_url/path_prefix/auth_tokens |
| 失败 | 401/超时/限流 |
| 验收 | 外部 Agent 可发现并调用 |

### M5 OpenAPI Blocking

| 项 | 内容 |
|---|---|
| 适用 | 系统集成、脚本 |
| 入口 | `/api/v1/agent/blocking/chat` |
| 认证 | API Key HMAC |
| 模式 | 同步（≤60s）/异步（202+task_id） |
| 配置 | scope=blocking、allowed_agents |
| 失败 | 403/429/超时 |
| 验收 | 第三方系统可拿到结果 |

### M6 Embed Bridge

| 项 | 内容 |
|---|---|
| 适用 | 嵌入门户/工作台 |
| 入口 | `/embed` |
| 认证 | 宿主 postMessage token |
| 流式 | SSE |
| 配置 | origin 白名单、spaceCode |
| 失败 | token 过期 → 请求宿主 |
| 验收 | 无二次登录、主题适配 |

## 2. 认证模式

| 模式 | 适用 | 凭据 | 过期 | 撤销 |
|---|---|---|---|---|
| SSO + JWT | Web/H5 | OIDC code → JWT | 15–30min | Redis 会话 |
| Refresh | 前端 | refresh token | 7–30d | 删 Redis |
| API Key | 系统 | app_id + HMAC | 长期 | 禁用/轮换 |
| A2A Bearer | Agent | token | 配置 | 轮换 |
| Bridge | 嵌入 | 宿主 token | 短期 | 宿主 |
| 服务 token | 内部 | mTLS/token | 短期 | 轮换 |

**选择**：用户走 SSO；系统走 API Key；嵌入走 Bridge；Agent 间走 A2A。

## 3. 运行模式

### R1 SSE 流式（默认）

```
POST /conversations/{id}/chat
→ text/event-stream
→ msg_start/token/tool/.../msg_end
```

- 适用：交互式对话。
- 优点：首 token 快、可续传。
- 注意：代理缓冲、心跳、断线重连。
- 失败：中断 → `/live` + Last-Event-ID。

### R2 Blocking 同步

```
POST /api/v1/agent/blocking/chat {async:false}
→ 等待 ≤60s → 200 + message
```

- 适用：脚本/简单集成。
- 注意：超时返回 202 + task_id。
- 失败：超时/429。

### R3 Blocking 异步

```
POST ... {async:true} → 202 + task_id
GET /api/v1/agent/blocking/result/{task_id}
```

- 适用：长任务/批处理。
- 注意：结果保留期、回调。
- 失败：任务失败/过期。

### R4 A2A Stream

- 适用：Agent 协作。
- 注意：Agent Card、认证、限流。

### R5 Feishu 卡片流

- 适用：IM。
- 注意：卡片更新频率限制、降级为文本。

### R6 后台任务

- 适用：定时/长任务。
- 注意：队列、超时、重试、通知。

## 4. Agent 模式

| 模式 | 配置 | 行为 | 适用 |
|---|---|---|---|
| 单 Agent | `multi_agent_enabled=0` | 单轮 ReAct | 大多数 |
| 多 Agent | `=1` | 规划+子 Agent | 复杂任务 |
| 有状态子 Agent | `sub_agent_stateful=true` | 保留子历史 | 连续追问 |
| 无状态子 Agent | `false` | 每次新上下文 | 独立任务 |
| 无沙箱 | `sandbox_mode=none` | 纯工具 | 问答 |
| 会话沙箱 | `session` | 绑定沙箱 | 代码 |
| 共享池 | `shared` | 共享槽位 | 低并发 |

**选择原则**：能用单 Agent 解决，不要多 Agent；能用无状态，不要有状态。

## 5. Skill 模式

| 模式 | 加载 | 上下文 | 成本 | 适用 |
|---|---|---|---|---|
| inline | 注入提示词 | 占 | 低 | 轻量规则 |
| on_demand | 按需读取 | 省 | 中 | 中等复杂 |
| subagent | 独立子会话 | 隔离 | 高 | 复杂/长任务 |

**配置**：`execution_mode`；`sandbox_requirement`；`skill_version`（固定/最新）。
**失败**：不可用 → 跳过 + 提示；沙箱不满足 → 拒绝。

## 6. 工具模式

| 模式 | 执行 | 适用 | 风险 |
|---|---|---|---|
| 内置 | Runtime | 时间/计算/文件 | 低 |
| HTTP | Runtime → API | 业务查询 | 中 |
| MCP | MCP Server | 标准工具 | 中 |
| Skill | inline/on-demand/subagent | 领域能力 | 中 |
| 沙箱 | Sandbox | 代码/Git | 高 |

**授权**：白名单 + 参数 Schema + 风险等级 + 高危审批。

## 7. 模型能力模式

| 模式 | 配置 | 行为 |
|---|---|---|
| Thinking | `supports_thinking` + 开关 | 输出思考过程 |
| Vision | `supports_vision` | 图片输入 |
| JSON Object | response_format | 结构化 |
| JSON Schema | response_format | 严格结构 |
| Tool Calling | tools | 工具调用 |

**规则**：能力不支持时明确报错，不静默降级。

## 8. 失败矩阵（跨模式）

| 模式 | 失败 | 用户可见 | 恢复 |
|---|---|---|---|
| Web SSE | 断线 | 续传中 | 自动重连 |
| Blocking | 超时 | 202 + task | 查询结果 |
| Feishu | WS 断 | 消息延迟 | 重连 |
| A2A | 401 | 调用失败 | 换 token |
| Bridge | token 过期 | 重新登录 | 宿主续 |
| Multi-Agent | 子任务失败 | 部分完成 | 重试/重规划 |
| Skill | 不可用 | 跳过 | 修复/解绑 |
| Sandbox | 创建失败 | 稍后重试 | 扩容/降级 |

## 9. 模式选择决策树

```
用户在哪里？
├─ Web/门户 → Web SSE（嵌入用 Bridge）
├─ 飞书 → 飞书机器人 + 卡片流
├─ 手机 → H5
└─ 系统 → API Key + Blocking/A2A

任务多复杂？
├─ 单步 → 单 Agent + inline/on_demand Skill
├─ 多步 → 单 Agent + 工具/MCP
└─ 复杂/长 → 多 Agent + subagent Skill + 沙箱

要代码执行？
├─ 否 → 无沙箱
└─ 是 → 会话沙箱（lazy/独占优先）
```
