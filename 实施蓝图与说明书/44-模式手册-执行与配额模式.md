# 44 模式手册：执行与配额模式

## 1. 沙箱生命周期模式

### S1 lazy（默认）

| 项 | 内容 |
|---|---|
| 行为 | 首次使用时创建 |
| 优点 | 不浪费空闲资源 |
| 缺点 | 首次延迟高 |
| 配置 | `creation_strategy=lazy`、`provision_timeout_seconds` |
| 适用 | 大多数场景 |
| 失败 | 创建超时 → 重试/提示 |

### S2 prewarm

| 项 | 内容 |
|---|---|
| 行为 | 预热池提前创建 |
| 优点 | 秒级可用 |
| 缺点 | 空闲成本 |
| 配置 | 池容量、模板、节点 |
| 适用 | 高并发/低延迟 |
| 失败 | 池空 → 回退 lazy |

### S3 shared pool

| 项 | 内容 |
|---|---|
| 行为 | 多主体共享槽位 |
| 优点 | 利用率高 |
| 缺点 | 数据残留/串扰 |
| 配置 | 池容量、重置策略 |
| 适用 | 低并发短任务 |
| 失败 | 槽位不足 → 排队/拒绝 |

### S4 ttl

| 项 | 内容 |
|---|---|
| 行为 | 到 TTL 销毁 |
| 配置 | `ttl_seconds` |
| 适用 | 短任务 |
| 注意 | 长任务需续期/超时 |

### S5 platform_idle

| 项 | 内容 |
|---|---|
| 行为 | 空闲暂停，暂停后销毁 |
| 配置 | `pause_after_seconds`、`delete_after_paused_seconds` |
| 适用 | 交互式 |
| 注意 | 恢复延迟 |

### S6 never_timeout

| 项 | 内容 |
|---|---|
| 行为 | 不自动销毁 |
| 适用 | 调试/长任务 |
| 风险 | 成本/泄漏 |

## 2. 沙箱访问模式

| 模式 | 说明 | 配置 |
|---|---|---|
| read | 只读 | `access_mode=read` |

## 3. Git 模式

| 模式 | token 来源 | 适用 | 风险 |
|---|---|---|---|
| caller | 调用方 | 用户自己的仓库 | token 传递 |
| platform | 平台编码账号 | 企业仓库 | 平台 PAT |
| fallback | 先 platform 后 caller | 兼容 | 复杂 |
| MR platform | 平台创建 MR | 标准 | — |
| MR skill | Skill 创建 | 自定义 | — |

**规则**：项目白名单；租约 TTL；回收；不落日志；审计。

## 4. 配额模式

### Q1 OBSERVE

| 项 | 内容 |
|---|---|
| 行为 | 只观测，不拒绝 |
| 用途 | 校准 TPM/缓存 |
| 指标 | would_wait/would_reject |
| 风险 | 实际成本可能超 |

### Q2 ENFORCE

| 项 | 内容 |
|---|---|
| 行为 | 强制准入/排队/拒绝 |
| 前提 | 参数确认 + 版本 |
| 指标 | 拒绝率/等待时间 |
| 风险 | 体验下降 |

### Q3 共享池

| 项 | 内容 |
|---|---|
| 行为 | 多模型共享 TPM |
| 优点 | 利用率高 |
| 风险 | 互相影响 |
| 配置 | pool_id 绑定多配置 |

### Q4 独占池

| 项 | 内容 |
|---|---|
| 行为 | 单模型/单业务 |
| 优点 | 隔离 |
| 成本 | 高 |
| 适用 | 关键业务 |

### Q5 不限流

| 项 | 内容 |
|---|---|
| 行为 | `configured_tpm=0` |
| 风险 | 成本失控 |
| 适用 | 内部测试 |

## 5. 配额参数调优

| 参数 | 建议 | 说明 |
|---|---|---|
| configured_tpm | 实测峰值 × 1.2 | 先 OBSERVE |
| burst_seconds | 30–120 | 吸收突发 |
| cache_ratio | 0.2–0.5 | 按供应商 |
| max_admission_wait_ms | 2000–5000 | 体验 |
| max_waiter_count | 20–100 | 防止堆积 |
| max_waiting_tokens | TPM × 0.5 | 防止预占过多 |

**调优流程**：OBSERVE 1–2 周 → 设保守 ENFORCE → 观察拒绝率 → 逐步收紧 → 大促扩容。

## 6. 任务模式

| 模式 | 触发 | 返回 | 适用 |
|---|---|---|---|
| 同步 | 请求 | 结果 | 短任务 |
| 异步 | 请求 | task_id | 长任务 |
| 回调 | 完成 | webhook | 系统集成 |
| 定时 | cron | 日志 | 运营 |
| 后台 | Agent | 通知 | 长时间 |

**状态**：queued → started → output → progress → completed/failed/cancelled。

## 7. 失败与降级

| 模式 | 失败 | 降级 |
|---|---|---|
| lazy | 创建超时 | 重试/提示 |
| prewarm | 池空 | 回退 lazy |
| shared | 槽位不足 | 排队/拒绝 |
| ENFORCE | 配额拒绝 | 429 + reset |
| Git platform | token 失败 | fallback caller |
| 异步任务 | 超时 | 取消/重试 |
| 后台 | 失败 | 通知/重试 |

## 8. 指标

| 指标 | 说明 |
|---|---|
| 创建成功率/耗时 | 沙箱 |
| 运行/暂停/失败数 | 容量 |
| 任务成功率/耗时 | 执行 |
| 配额拒绝率/等待 | 模型 |
| 超发率 | 对账 |
| 沙箱成本 | 归因 |

## 9. 模式选择决策树

```
需要代码执行？
├─ 否 → 无沙箱
└─ 是 → 并发高？
    ├─ 是 → prewarm + 共享池
    └─ 否 → lazy + 会话沙箱（platform_idle）
需要企业仓库？
├─ 是 → platform Git + 白名单
└─ 否 → caller Git
成本敏感？
├─ 是 → OBSERVE 校准 → ENFORCE 共享池
└─ 否 → 独占池/不限流
任务长？
├─ 是 → 异步 + 回调 + 超时
└─ 否 → 同步
```
