# 45 模式手册：部署与交付模式

## 1. 模式总览

| 模式 | 适用 | 复杂度 | 成本 | 隔离 |
|---|---|---|---|---|
| D1 本地 Compose | 开发/演示 | 低 | 低 | 无 |
| D2 单机部署 | 小团队/试点 | 低 | 低 | 弱 |
| D3 K8s 单地域多 AZ | 生产默认 | 中 | 中 | 中 |
| D4 多租户共享 | SaaS 小租户 | 中高 | 中 | 逻辑 |
| D5 私有化 | 大客户/合规 | 高 | 高 | 强 |
| D6 SaaS | 对外商业化 | 高 | 高 | 强 |
| D7 混合云 | 数据驻留 | 高 | 高 | 强 |

---

## 2. D1 本地 Compose

```yaml
services:
  mysql: mysql:8
  redis: redis:7
  minio: minio/minio
  api: build ./backend
  runtime: build ./agent-runtime
  web: build ./frontend
```

| 项 | 内容 |
|---|---|
| 适用 | 开发、Demo、CI |
| 数据 | 本地卷 |
| 认证 | Mock SSO/固定 token |
| 模型 | Mock/测试 Key |
| 沙箱 | Docker（仅本地） |
| 备份 | 不需要 |
| 优点 | 1 小时跑起来 |
| 缺点 | 无 HA/无隔离 |
| 验收 | 黄金路径可演示 |

---

## 3. D2 单机部署

```
Nginx → API/Runtime/Worker → MySQL/Redis/MinIO
```

| 项 | 内容 |
|---|---|
| 适用 | 10–50 人试点 |
| 规格 | 8C32G + 500GB |
| 进程 | systemd/docker compose |
| 备份 | 每日 mysqldump + OSS |
| 升级 | 蓝绿目录/停机窗口 |
| 风险 | 单点 |
| 验收 | 可恢复、可升级 |

---

## 4. D3 K8s 单地域多 AZ（推荐生产）

```
Ingress/WAF
  ├─ api (3+)
  ├─ runtime (3+)
  ├─ sse-gateway (2+)
  ├─ worker (2+)
  └─ sandbox-worker (node pool)
MySQL 主从跨 AZ
Redis Sentinel/Cluster
OSS + CDN
```

| 项 | 内容 |
|---|---|
| 适用 | 企业生产 |
| 节点池 | system/app/sse/sandbox |
| 隔离 | namespace + NetworkPolicy |
| 发布 | 金丝雀/蓝绿 |
| 备份 | 每日全备 + binlog |
| RTO/RPO | ≤30min / ≤15s |
| 成本 | 中 |
| 验收 | 单 AZ 故障可切换 |

---

## 5. D4 多租户共享

| 级别 | 隔离 | 适用 |
|---|---|---|
| L1 共享表 | tenant_id | 小租户 |
| L2 独立 schema | schema | 中 |
| L3 独立库 | DB | 大客户 |
| L4 独立部署 | 集群 | 私有化 |

**要求**：租户解析、配额、缓存/OSS 前缀、审计、跨租户测试。
**风险**：邻居打爆、数据泄露。
**验收**：跨租户 0 成功；配额隔离；按租户计费。

---

## 6. D5 私有化

| 项 | 内容 |
|---|---|
| 交付 | Helm Chart + 离线镜像 + 安装脚本 |
| 依赖 | 客户 DB/Redis/OSS/SSO |
| 模型 | 客户网关/私有化模型 |
| 升级 | 离线包/灰度 |
| 支持 | 远程/驻场 |
| 成本 | 高 |
| 验收 | 离线安装、升级、回滚 |

**注意**：不要假设有公网；所有外部依赖可替换/Mock；许可证/审计。

---

## 7. D6 SaaS

| 项 | 内容 |
|---|---|
| 租户 | 注册/开通/计费 |
| 隔离 | L1–L3 |
| 配额 | 按套餐 |
| 合规 | 数据驻留/删除/导出 |
| 运营 | 试用/转化/流失 |
| 成本 | 单位经济模型 |
| 验收 | 计费准确、隔离、SLA |

**前提**：身份/计费/运营/合规模块齐全，不建议 MVP 做 SaaS。

---

## 8. D7 混合云

- 控制面在云，沙箱/模型在客户侧；或反之。
- 专线/VPN；数据不出域。
- 延迟/带宽/故障域复杂。
- 仅在有明确合规/数据驻留需求时采用。

---

## 9. 环境与晋升

```
local → dev → test → uat → prod
```

| 环境 | 数据 | 外部集成 | 发布 |
|---|---|---|---|
| local | mock | mock | 手动 |
| dev | 种子 | mock/测试 | 自动 |
| test | 脱敏 | 测试 | 自动 |
| uat | 仿真 | 测试 | 审批 |
| prod | 真实 | 生产 | 灰度 |

**规则**：配置/密钥独立；禁止测试访问生产；晋升需质量门禁。

---

## 10. 发布模式

| 模式 | 适用 | 回滚 |
|---|---|---|
| 滚动 | 常规 | 镜像回滚 |
| 蓝绿 | 大版本 | 切流量 |
| 金丝雀 | 高风险 | 停灰度 |
| 特性开关 | 功能 | 关开关 |

**观察**：错误率、延迟、SSE 断连、模型错误、配额拒绝。

---

## 11. 备份与容灾

| 组件 | 备份 | RPO | RTO |
|---|---|---|---|
| MySQL | 全备+binlog | ≤15s | ≤5min |
| Redis | AOF/RDB | ≤1s | ≤1min |
| OSS | 版本/跨区 | ≈0 | 分钟 |
| 配置 | Git | 0 | 分钟 |
| 密钥 | Vault 备份 | 0 | 分钟 |

**演练**：每季度恢复；每半年切换。

## 13. 选择决策树

```
只是演示？ → D1
10–50 人试点？ → D2
企业生产？ → D3
多租户 SaaS？ → D4/D6
客户要求私有化？ → D5
数据必须驻留？ → D7
```
