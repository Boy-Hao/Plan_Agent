## 14. 配置校验

```python
class Settings(BaseSettings):
    app_env: Literal["dev","test","uat","prod"] = "dev"
    db_url: PostgresDsn | str
    jwt_secret: SecretStr
    @field_validator("jwt_secret")
    def strong(cls, v):
        if len(v.get_secret_value()) < 32: raise ValueError("too short")
        return v
```

- 启动时校验必填/长度/URL；失败拒绝启动。
- 密钥不打印；日志只显示 `***`。
- 配置变更审计；支持回滚。

## 15. 验收标准

- [ ] 所有配置有名称/默认/说明/是否敏感。
- [ ] 启动时校验，缺失/非法即失败。
- [ ] 密钥只从 Secret 注入，不落代码/日志。
- [ ] 环境矩阵清晰，禁止跨环境复用。
- [ ] 特性开关可灰度、可回滚。
- [ ] 调优参数有基线值。
