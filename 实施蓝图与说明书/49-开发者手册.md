## 3. 后端规范

### 3.1 命名

- 类 `PascalCase`；函数/变量 `snake_case`；常量 `UPPER_SNAKE`。
- API 路由复数；Schema `XxxCreate/XxxUpdate/XxxResponse`。
- 事件 `Domain.Action`（如 `Agent.Updated`）。

### 3.2 分层

| 层 | 允许 | 禁止 |
|---|---|---|
| api | 参数/鉴权/响应 | SQL/业务规则 |
| application | 编排/事务/权限 | 直接 SQL |
| domain | 规则/不变量 | 框架/SDK |
| infra | SQL/外部适配 | 业务规则 |

### 3.3 事务

```python
async with self.uow:
    await self.repo.add(entity)
    await self.outbox.add(Event(...))
```

- 一个用例一个事务；跨服务用 outbox。
- 禁止在循环里开事务。

### 3.4 错误

```python
raise AppError(code="not_found", message="...", status=404)
```

- 不抛裸 `Exception`；不泄露堆栈。
- 统一异常处理器输出 envelope。

### 3.5 日志

```python
logger.info("llm_call", extra={"request_id":..., "session_id":..., "model":...})
```

- 结构化 JSON；不记录 prompt/密钥。
- 关键路径有 request_id/trace_id。

## 4. 前端规范

- 组件函数式 + hooks；页面只组合。
- 请求放 `features/*/api`；状态 Query/Zustand。
- 表单 React Hook Form + Zod。
- 样式用设计 token；禁止魔法色值。
- 权限用 `usePermission`，后端仍强校验。
- SSE 解析独立 `lib/sse.ts`，可单测。

---

## 5. 新增模块模板

1. `domain/`：实体/值对象/规则 + 单测。
2. `infra/`：表/迁移/repository + 集成测试。
3. `application/`：service/事务/事件。
4. `api/`：schema/route/权限/OpenAPI。
5. `frontend/features/<module>`：api/hooks/页面。
6. 指标/日志/Trace/配置/测试/文档。

**DoD**：见 34 的模块 Definition of Done。

## 8. 调试

### 8.1 SSE

- `curl -N` 看事件流。
- 检查代理是否缓冲（`X-Accel-Buffering: no`）。
- Redis：`XLEN sse:log:{mid}`、`GET active_turn`。

### 8.2 LLM

- 用 mock provider 复现。
- 记录 request_id/model/token/延迟。
- 检查上下文是否超限、工具 Schema 是否合法。

### 8.3 沙箱

- 看创建事件/日志；检查网络策略。
- 确认 per-run env 白名单。
- 隔离验证：`curl 169.254.169.254` 应失败。

### 8.4 权限

- 打印 claims/roles/permissions（脱敏）。
- 检查资源 ACL/租户。
- 用不同角色跑矩阵。

## 10. 常见坑

| 坑 | 规避 |
|---|---|
| 忘记 tenant_id | Repository 默认注入 |
| 事务里调外部 API | 先落库/outbox，再异步 |
| SSE 被代理缓冲 | `X-Accel-Buffering: no` + flush |
| 事件无版本 | schema version |
| 软删后唯一冲突 | 应用层校验范围 |
| N+1 查询 | 批量 IN / join |
| 大对象进日志 | 截断/脱敏 |
| 前端直连厂商 | 后端适配器 |
| 迁移不可回滚 | 写 downgrade + 演练 |
| 只测 happy path | 失败/边界用例 |
