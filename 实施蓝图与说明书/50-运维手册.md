- [ ] 队列积压/死信
- [ ] 模型 429/错误率/成本
- [ ] 沙箱创建失败/孤儿
- [ ] 备份完成
- [ ] 告警/工单

---

## 2. 部署

### 2.1 标准发布

```
1. 合并代码 → CI（lint/test/build/scan）
2. 构建镜像（固定 digest）
3. 部署 dev → smoke
4. 部署 test → E2E
5. 审批 → uat → 验收
6. prod 金丝雀 5% → 25% → 100%
7. 观察 30min → 完成
```

### 2.2 数据库迁移

```
备份 → 预检 → 迁移 → 校验 → 观察 → 清理
```

- 迁移先于应用；兼容旧版本。
- 大表 online DDL；低峰执行。
- 回滚脚本准备。

### 2.3 回滚

```
1. 停止灰度/切回旧版本
2. 回滚镜像/配置
3. 必要时回滚迁移
4. 验证核心链路
5. 记录事件
```

## 3. 备份与恢复

| 组件 | 频率 | 保留 | 恢复 |
|---|---|---|---|
| MySQL 全备 | 每日 | 30 天 | `mysql < backup.sql` |
| binlog | 持续 | 7 天 | 时间点恢复 |
| Redis RDB/AOF | 持续 | 7 天 | 重启加载 |
| OSS | 版本 | 30 天 | 版本恢复 |
| 配置 | Git | 永久 | `git revert` |
| 密钥 | Vault | 按策略 | 恢复流程 |

**演练**：每季度一次；记录 RTO/RPO；问题闭环。

## 4. 监控与告警

### 4.1 看板

- 总览：QPS/错误/延迟/活跃
- AI：模型延迟/错误/token/成本/配额
- SSE：连接/断连/续传
- 沙箱：创建/运行/失败/回收
- DB/Redis：连接/慢查/内存
- 集成：飞书/GitLab/A2A
- 业务：DAU/Agent/Skill/反馈

### 4.2 告警

| 级别 | 例子 | 响应 |
|---|---|---|
| P0 | 登录全挂/5xx>10%/DB 不可用 | 电话 5min |
| P1 | 首 token P95>8s/错误>5%/队列>10min | 15min |
| P2 | 配额拒绝>10%/沙箱失败>5%/容量>80% | 1h |
| P3 | 单 Agent 异常/成本波动 | 次日 |

**要求**：告警有 Runbook；聚合/抑制；值班轮换。

## 5. Runbook

### 5.1 登录失败

```
1. 查 SSO 健康/证书/回调白名单
2. 查 /auth/sso/config 是否 200
3. 查 Redis 会话/时间同步
4. 回滚最近配置
5. 通知用户
```

### 5.2 对话 5xx

```
1. 看错误码分布（模型/DB/Redis/工具）
2. 查最近发布/配置
3. 熔断异常依赖/切备用
4. 限流非核心
5. 回滚
```

### 5.3 模型 429

```
1. 确认 Provider/模型/租户
2. 切备用模型/降低后台优先级
3. 429 + Retry-After
4. 联系供应商/扩容
5. 复盘配额
```

### 5.4 Redis 故障

```
1. 确认主从/集群状态
2. SSE 降级（提示重连）
3. 锁降级 DB/拒绝并发写
4. 恢复/切主
5. 校验会话/配额
```

### 5.5 MySQL 主从切换

```
1. 停止写入/切只读
2. 提升从库/切换 VIP
3. 应用重连
4. 校验数据/复制
5. 恢复写入
```

### 5.6 沙箱异常

```
1. 查创建失败/节点/镜像
2. 批量 kill 异常实例
3. 隔离节点/扩容
4. 降级只读工具
5. 复盘
```

### 5.7 飞书 WS 断连

```
1. 查 ws_status/last_error
2. 触发重连
3. 检查密钥/网络
4. 降级到 Web 入口
```

### 5.8 OSS 容量/回收

```
1. 查水位/增长
2. 生命周期/冷归档
3. 盘点孤儿
4. 安全回收（审批）
5. 扩容
```

## 6. 容量

| 资源 | 阈值 | 动作 |
|---|---|---|
| API CPU | >60% 10min | 扩容 |
| Runtime 并发 | >70% | 扩容 |
| SSE 连接 | >70% | 加节点 |
| MySQL 连接 | >70% | 调池/扩读 |
| Redis 内存 | >70% | 扩容/清理 |
| 沙箱使用率 | >70% | 加节点 |
| OSS | >80% | 扩容/清理 |

**压测**：季度/大促前；基线对比；容量报告。

## 7. 安全运维

- 密钥轮换（半年/泄露）。
- 依赖/镜像扫描；高危 7 天修复。
- 审计日志检查；异常登录告警。
- 沙箱逃逸演练；补丁。
- 权限复核（季度）。
- 备份加密/访问控制。

---

## 8. 事件管理

```
发现 → 分级 → 止损 → 定位 → 修复 → 恢复 → 复盘
```

**复盘模板**：时间线、影响、根因、改进项、责任人、截止。

**原则**：不追责个人；关注系统改进；改进项跟踪到关闭。

---

## 9. 值班

- 7×24 轮换；交接记录。
- P0 5min 响应；P1 15min。
- 升级路径：值班 → 负责人 → CTO。
- 告警静默需审批。

---

## 10. 变更管理

| 变更 | 审批 |
|---|---|
| 常规发布 | Tech Lead |
| 数据库迁移 | DBA/架构 |
| 密钥/权限 | 安全 |
| 配额模式 | 负责人 |
| 大范围推送 | 业务+安全 |

- 变更窗口；避开高峰。
- 变更记录/回滚方案。
