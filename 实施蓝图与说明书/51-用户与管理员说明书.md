# 51 用户、建设者与管理员说明书

> 面向三类角色：**使用者**、**Agent 建设者**、**平台管理员**。

---

## 第一部分：使用者

### 1. 登录

1. 打开平台地址。
2. 跳转企业 SSO，输入账号/完成认证。
3. 首次登录自动创建账号。
4. 登录后进入首页/Agent 广场。

**常见问题**
- 一直跳登录：检查 SSO/回调；清理缓存。
- 无权限：联系管理员分配角色。

### 2. 找 Agent

- 首页推荐/搜索/分类。
- 可见范围：公开、受限（需授权）、私有（仅自己）。
- 点击卡片查看描述、示例、快捷开始。

### 3. 对话

1. 选择 Agent → 新建会话。
2. 输入问题；可上传附件、选择引用源、插入技能。
3. 流式回复；可停止/继续。
4. 可切换模型、开关思考（如支持）。
5. 可点赞/点踩并填写原因。

**技巧**
- 问题具体：给背景、目标、格式。
- 附件先上传再提问。
- 长任务用「任务计划」查看进度。
- 刷新/断网会自动续传。

### 4. 附件与文件

- 支持类型/大小见上传提示。
- 上传后可预览/下载。
- 删除进回收站，30 天内可恢复。
- 个人文件在「个人文件」管理。

### 5. 技能

- Agent 已启用的技能会自动可用。
- 输入 `/` 或「技能」按钮查看/启用。
- 个人 Skill 默认关闭，可在设置启用。
- 共享 Skill 需接受/启用。

### 6. 飞书

- 绑定飞书账号后可在私聊/群聊使用。
- 未绑定会收到绑定引导。
- 授权过期会提示重新授权。

### 7. 反馈与问题

- 点踩并说明问题，帮助改进。
- 查看「我的用量」了解消耗。
- 联系管理员/支持群。

## 第二部分：Agent 建设者

### 1. 创建 Agent

1. 进入「智能体管理」→ 新建。
2. 填写名称、描述、系统提示词。
3. 选择可见性（公开/受限/私有）。
4. 保存。

### 2. 系统提示词

建议结构：

```
# 角色
你是...

# 目标
...

# 输入
...

# 步骤
1. ...
2. ...

# 输出格式
...

# 边界
- 不知道时...
- 不执行...
```

**技巧**：给示例、明确拒答、要求引用来源。

### 3. 绑定模型

- 选择一个或多个模型，设默认。
- 配置参数（temperature/top_p/最大输出/思考/视觉）。
- 保存前可测试连通性。
- 能力变更会提示影响。

### 4. 绑定技能

- 选择 Skill；建议固定版本。
- 查看不可用原因（沙箱/权限/个人未启用）。
- 可设置用户是否可取消。

### 5. 工具与 MCP

- 系统工具：勾选/配置。
- MCP：填 URL/headers（变量引用）/工具范围；先测试。
- 高危工具需审批/二次确认。

### 6. 变量/模板/引用源

- Agent 变量：`agt_*`，密钥类掩码。
- 模板：按业务分组，可插入变量/引用源。
- 引用源：查询 URL、单选/级联、给模型的描述。

### 7. 快捷开始/业务分组

- 按 `biz_id` 配置快捷按钮。
- 排序/启停；影响用户首屏。

### 8. 子 Agent

- 选择可调用 Agent；配置超时/预算/报告。
- 避免循环；删除前看影响。

### 9. 测试与发布

- 用测试会话验证：正常/边界/失败。
- 检查工具调用、引用、格式。
- 发布后观察反馈/用量。

### 10. 协作

- 添加协作者（可编辑）。
- 转移 owner（需目标有创建权限）。
- 删除前查看影响（会话/调度/子 Agent）。

## 第三部分：平台管理员

### 1. 用户与角色

- 用户列表：搜索/状态/最后登录。
- 分配角色；角色含权限点。
- 权限点分组勾选；保存后清缓存。
- 高危权限变更审计。

### 2. 模型管理

- 新增模型：Provider/地址/Key/模型/价格/能力。
- 测试连通性；查看绑定 Agent。
- 删除前影响分析；解绑。
- 配额池：创建/确认/模式切换/归档。

### 3. 配额池

1. 创建池，填 TPM/突发/缓存/等待。
2. OBSERVE 观察 1–2 周。
3. 确认参数，切 ENFORCE。
4. 看拒绝率/等待/成本；调整。
5. 归档闲置池。

**注意**：切换需版本号 + 原因；强制模式需确认。

### 4. 沙箱

- 配置：domain/template/TTL/生命周期/Git/代理。
- 实例：状态/暂停/恢复/杀/批量。
- 任务：事件/日志/取消。
- 定期 reconcile 清理孤儿。

### 5. 飞书

- 新建应用配置（app_id/secret/encrypt/verification）。
- 绑定 Agent；开启对话。
- 查看 WS 状态；重连。
- 事件目录/Agent 白名单/用户订阅。
- 推送：模板/卡片/部门/用户/进度/撤回。

### 6. GitLab

- 同步源：地址/项目/分支/目录/Token。
- 预览/执行/重试。
- OAuth 用户授权/撤销。
- 编码账号：验证/项目白名单/租约回收。

### 7. 权限审计

- 申请：权限点/理由/期限。
- 审批：通过/拒绝。
- 授权：到期/释放/撤销。
- 配置：审计开关（双人审批）。
- 证据/导出：脱敏下载。

### 8. 用量与成本

- 汇总：调用/token/费用。
- 维度：用户/Agent/模型/会话/时间。
- TopN/趋势；导出。
- 预算告警；异常排查。

### 9. OSS 治理

- 概览：容量/对象/成本。
- 盘点：创建/进度/差异/重试。
- 孤儿：核验/归属/回收。
- 版本：恢复。
- 门禁：发布前检查。

### 10. 审计与通知

- 审计：谁/何时/对象/前后值/IP。
- 导出：脱敏/水印。
- 通知：未读/已读/类型。

## 第四部分：FAQ

| 问题 | 处理 |
|---|---|
| 登录一直跳转 | 检查 SSO/回调/时钟 |
| 对话无响应 | 查模型/配额/网络；看错误码 |
| 首 token 慢 | 模型/上下文/排队；切换/裁剪 |
| 技能不生效 | 检查绑定/版本/启用/沙箱 |
| 附件上传失败 | 类型/大小/配额/病毒扫描 |
| 沙箱创建失败 | 容量/模板/网络；重试 |
| 飞书无回复 | WS/绑定/Agent 配置 |
| 推送失败 | 应用权限/open_id/频率 |
| 用量异常 | 查 TopN/重试/缓存 |
| 权限不足 | 角色/ACL/数据范围 |
| 审批卡住 | 审批人/策略/转交 |
| 成本超预算 | 配额/模型分级/缓存 |
