# 52 快速启动与验收清单

## 1. 1 小时：本地跑起来

### 1.1 准备

```bash
git clone <repo>
cd cloud-agent-platform
cp .env.example .env
docker compose up -d mysql redis minio
```

### 1.2 初始化

```bash
make install
make migrate
make seed
make api &
make runtime &
make web
```

### 1.3 验证

- [ ] `http://localhost:8000/health.json` 返回 ok
- [ ] `http://localhost:5173` 可打开
- [ ] 登录（mock SSO）
- [ ] 看到 Demo Agent
- [ ] 发一条消息，流式返回
- [ ] 刷新，历史还在

**通过标准**：30 分钟内完成，无需外部依赖。
