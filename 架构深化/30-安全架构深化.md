# 30 安全架构深化

## 1. 安全架构总览

```
┌──────────────┐
│ 用户/浏览器   │
└──────┬───────┘
       │ TLS / WAF / CSP
┌──────▼───────────────────────────────────────────────┐
│ 边缘层：Ingress / API Gateway / Rate Limit            │
└──────┬───────────────────────────────────────────────┘
       │ mTLS / Token
┌──────▼──────────────┐   ┌────────────────────────────┐
│ 控制面 Control Plane │   │ 身份面 Identity Plane       │
│ 配置/权限/审计       │◀─▶│ SSO / JWT / RBAC / Tenant   │
└──────┬──────────────┘   └────────────────────────────┘
       │ 只读配置 / 事件
┌──────▼──────────────┐
│ 数据面 Runtime       │───▶ 模型网关 ───▶ Provider
│ 会话/编排/工具        │───▶ 沙箱 ─────▶ 执行环境
└──────┬──────────────┘
       │
┌──────▼──────────────┐
│ 数据层 MySQL/Redis/OSS│
└─────────────────────┘
```

**核心原则**：控制面不执行不可信代码；数据面不持有长期密钥；沙箱不访问控制面数据。

---

## 2. 信任边界

| 边界 | 跨越 | 威胁 | 控制 |
|---|---|---|---|
| B1 用户→边缘 | 公网 | CSRF/XSS/DDoS | TLS、WAF、CSP、限流 |
| B2 边缘→控制面 | 内网 | 伪造 token/越权 | JWT 验签、mTLS、RBAC |
| B3 控制面→数据面 | 内网 | 越权读配置/写数据 | 只读账号、接口鉴权、租户 |
| B4 数据面→模型 | 外网/专线 | 数据出境/密钥泄露 | 网关、脱敏、合规 |
| B5 数据面→沙箱 | 内网 | 逃逸/横向移动 | 强隔离、无长密钥、网络策略 |
| B6 控制面→集成 | 外网 | token 泄露/SSRF | 加密、白名单、租户 |
| B7 管理端→生产 | 内网/VPN | 误操作/提权 | 审批、双人、审计 |

## 3. 租户隔离

### 3.1 隔离级别

| 级别 | 说明 | 适用 |
|---|---|---|
| L1 共享库共享表 | `tenant_id` 过滤 | 首版/SaaS 小租户 |
| L2 共享库独立 schema | 每租户 schema | 中大型 |
| L3 独立库 | 每租户 DB | 大客户/合规 |
| L4 独立部署 | 独立集群 | 私有化 |

### 3.2 强制隔离

- 网关解析租户（域名/Token claim/Header），写入 `TenantContext`。
- Repository 层强制 `tenant_id`；禁止裸 SQL；ORM 默认过滤。
- Redis key、OSS 前缀、日志/指标标签全带租户。
- 跨租户测试：用两个租户账号互相访问，期望 404/403。
- 管理端「跨租户」能力仅超级管理员，且审计。

## 4. 身份与密钥

### 4.1 身份

| 身份 | 凭据 | 生命周期 |
|---|---|---|
| 用户 | SSO + JWT | access 15–30min，refresh 7–30d |
| 服务 | mTLS/服务 token | 短期 |
| API Key | app_id + HMAC | 长期，可轮换 |
| 沙箱 | 短期租约 | 分钟级 |
| 飞书/GitLab | OAuth token | 加密、可撤销 |
| 模型 | API Key | 加密、可轮换 |

### 4.2 密钥生命周期

```
生成 → 加密存储 → 使用 → 轮换 → 吊销 → 审计
```

- 信封加密：KMS 主密钥加密数据密钥，数据密钥加密业务密钥。
- 密钥版本化；轮换不中断（双版本过渡）。
- 禁止明文落库/日志/镜像/前端。
- 泄露应急预案：轮换、撤销会话、排查、通知。

## 5. 沙箱安全架构

| 层 | 控制 |
|---|---|
| 宿主 | 独立节点池、专用账号、内核补丁 |
| 隔离 | microVM/gVisor；独立内核/命名空间 |
| 网络 | 默认拒绝；出站白名单；禁内网/元数据 |
| 文件 | 独立工作目录；只读根；任务后清理 |
| 凭证 | 短期租约；不注入长期密钥；代理 |
| 资源 | CPU/内存/磁盘/进程/时间限额 |
| 镜像 | 签名、扫描、固定 digest、最小化 |
| 行为 | 命令审计、异常检测、超限终止 |
| 演练 | 逃逸/提权/横向移动测试 |

**红线**：Docker 容器不作为多租户安全边界；沙箱节点不得挂载宿主敏感目录；不得访问 K8s API。

## 6. Prompt 注入防御

| 层 | 措施 |
|---|---|
| 输入 | 意图识别、注入模式检测、长度/频率限制 |
| 上下文 | 系统提示词优先级；外部内容标记为「数据」 |
| 工具 | 白名单、参数 Schema、权限校验、高危二次确认 |
| 输出 | 脱敏、DLP、内容审核 |
| 运行 | 沙箱隔离、最小权限、审计 |
| 运营 | 红队用例、badcase 库、持续评测 |

**原则**：模型输出永远不可信；副作用操作必须经过工具层授权，而不是仅靠 Prompt。

---

## 7. 工具授权模型

```json
{
  "tool": "send_feishu_message",
  "risk": "write",
  "scopes": ["feishu:message:send"],
  "resource": "feishu_config_id",
  "approval": "required_for_external",
  "rate_limit": "10/min"
}
```

- 工具声明风险等级（read/write/danger）。
- 调用前校验：用户权限 + Agent 授权 + 资源范围 + 配额。
- 高危工具需人工确认/审批；记录谁批准。
- 工具结果脱敏后再回填模型。

---

## 8. 供应链安全

- 依赖锁定 + SCA（pip/npm）。
- 镜像扫描 + 签名 + 准入控制（cosign/OPA）。
- Skill 包扫描：脚本、依赖、网络、路径。
- CI 密钥最小化；不落日志。
- 第三方 SDK 评估数据流向。
- 供应商安全评估（模型/沙箱/云）。

---

## 9. 审计与证据链

| 事件 | 记录 |
|---|---|
| 登录/登出/失败 | 用户、IP、UA、结果 |
| 权限变更 | 操作人、对象、前值/后值 |
| 密钥操作 | 创建/轮换/禁用（不记录明文） |
| 模型配置 | 变更、影响范围 |
| 配额模式切换 | 版本、原因、操作人 |
| 沙箱/文件回收 | 原因、影响、恢复版本 |
| 导出 | 查询条件、下载人、水印 |

**防篡改**：哈希链/只追加存储；定期归档 WORM；导出脱敏。

## 11. 验收标准

- [ ] 跨租户/跨用户访问 0 成功。
- [ ] 密钥不出现于日志/镜像/前端/沙箱。
- [ ] 沙箱逃逸演练通过，补丁 SLA ≤ 7 天。
- [ ] Prompt 注入红队用例拦截率达标。
- [ ] 高危操作 100% 审计，证据可导出。
- [ ] 供应链高危漏洞 0。
