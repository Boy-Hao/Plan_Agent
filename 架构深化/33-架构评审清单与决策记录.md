## 3. 架构检查表

### 3.1 领域与模块

- [ ] 限界上下文清晰，数据 Owner 唯一。
- [ ] 模块依赖规则可执行（CI）。
- [ ] 聚合不变量有测试。
- [ ] 跨上下文只通过 API/事件。
- [ ] 团队拓扑与上下文一致。

### 3.2 运行时

- [ ] Turn 状态机完整，终态不可变。
- [ ] 会话锁有 fencing token。
- [ ] 幂等键覆盖消息/工具/回调。
- [ ] 取消可传播到模型/工具/子 Agent。
- [ ] 断线续传不丢/不重。
- [ ] 子 Agent 有预算/超时/摘要。
- [ ] 事件 schema 有版本。

### 3.3 数据

- [ ] 强一致/最终一致边界明确。
- [ ] Outbox/Inbox 落地。
- [ ] 大表分区/归档。
- [ ] 索引覆盖核心查询。
- [ ] Redis 结构/内存/淘汰策略。
- [ ] 迁移可回滚。

### 3.4 模型与配额

- [ ] 多 Provider/备用模型。
- [ ] 能力注册表 + 参数合并可解释。
- [ ] 配额 Lua 原子 + 对账。
- [ ] 用量可追溯到调用。
- [ ] 降级/熔断/重试参数明确。

### 3.5 沙箱

- [ ] 强隔离，无宿主/内网访问。
- [ ] 镜像签名/扫描/固定 digest。
- [ ] 短期凭证/租约/回收。
- [ ] 网络默认拒绝 + 白名单。
- [ ] 逃逸演练 + 补丁 SLA。

### 3.6 安全

- [ ] 信任边界/认证/加密。
- [ ] 租户隔离强制 + 测试。
- [ ] 密钥生命周期。
- [ ] Prompt 注入/工具授权。
- [ ] 审计/证据/导出。
- [ ] 供应链安全。

### 3.7 可运维

- [ ] 指标/日志/Trace 关联会话。
- [ ] SLO/错误预算/告警。
- [ ] Runbook/值班/演练。
- [ ] 容量模型/压测基线。
- [ ] 备份/恢复/容灾。

### 3.8 成本

- [ ] 模型/沙箱/存储成本归因。
- [ ] 预算/告警/配额。
- [ ] 单位经济模型。
- [ ] 降本路线。
