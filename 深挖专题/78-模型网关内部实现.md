# 78 模型网关内部实现

## 1. 目标

把「多 Provider、多模型、多能力」统一成稳定接口：

- 业务只传 `llm_config_id` + 消息 + 工具；
- 网关负责路由、配额、重试、降级、计费、观测；
- 不让厂商差异泄漏到业务。

---

## 2. 内部模块

```
Gateway API
  ├─ Auth/租户/配额
  ├─ Router（模型选择）
  ├─ Adapter（Provider 归一化）
  ├─ Stream Normalizer（统一 chunk）
  ├─ Usage Extractor（token/费用）
  ├─ Retry/Circuit Breaker
  └─ Observability
```

---

## 3. 统一请求

```python
@dataclass
class ChatRequest:
    tenant_id: str
    agent_id: str
    llm_config_id: str
    messages: list[Message]
    tools: list[ToolSpec] | None
    temperature: float | None
    max_output_tokens: int | None
    response_format: dict | None
    stream: bool = True
    metadata: dict = field(default_factory=dict)
```

---

## 4. 统一响应/流

```python
@dataclass
class Chunk:
    type: Literal["text", "thinking", "tool_call", "tool_result", "usage", "done", "error"]
    delta: str | None = None
    tool_call: ToolCall | None = None
    usage: Usage | None = None
    error: GatewayError | None = None
```

**归一化要点**
- OpenAI/Anthropic 的 tool call 格式不同 → 统一。
- 思考内容 → `thinking`。
- 结束原因 → `done.finish_reason`。
- 用量 → 统一 token 字段。

---

## 5. Provider 适配

```python
class ProviderAdapter(Protocol):
    async def chat(self, req: ChatRequest) -> AsyncIterator[Chunk]: ...
    def capabilities(self, model: str) -> ModelCapabilities: ...
    async def ping(self) -> PingResult: ...
```

| Provider | 差异 |
|---|---|
| OpenAI 兼容 | 大多数国产模型 |
| Anthropic | messages/thinking/tool use |
| Azure | deployment/api-version |
| 自建 vLLM | 能力有限 |
| 网关 | 错误/用量映射 |

**错误归一**：auth/rate_limit/timeout/context_overflow/content_blocked/unsupported/server。

---

## 6. 路由

```
显式模型 → 能力过滤 → 配额 → 调用
未指定 → Agent 默认 → 任务路由 → 备用 → 全局默认
```

- 能力：工具/视觉/思考/JSON/上下文。
- 成本/延迟：小模型优先/大模型兜底。
- 合规：敏感数据 → 私有化。
- 路由结果记录（可解释）。

---

## 7. 配额

```
effective = prompt × (1 - cache_hit × (1 - cache_ratio))
bucket = min(capacity, bucket + elapsed × tpm/60)
if bucket >= effective: admit
else: OBSERVE/queue/429
```

- Redis Lua 原子；服务端时间。
- 分片防热 key；快照/对账。
- OBSERVE 记录 would_wait/reject。
- ENFORCE 需参数确认 + 版本。

---

## 8. 流式归一化

| 厂商 | 原始 | 统一 |
|---|---|---|
| OpenAI | `choices[0].delta.content` | `text` |
| Anthropic | `content_block_delta` | `text/thinking` |
| Tool | `tool_calls` | `tool_call` |
| Usage | 末尾/单独 | `usage` |
| Done | `[DONE]`/stop | `done` |

**注意**：流中断要发 `error`；不要静默结束。

---

## 9. 用量与计费

```
cost = (prompt - cached) × price_in
     + cached × price_cache
     + completion × price_out
```

- 单价按调用时快照。
- 缓存 token 单独记。
- 失败/取消也记（部分用量）。
- 与供应商账单对账。

## 10. 重试/熔断

| 错误 | 重试 | 备用 |
|---|---|---|
| 429 | 等待/排队 | 是 |
| 5xx | 1 次 | 是 |
| 超时 | 1 次 | 是 |
| 401/403 | 否 | 否 |
| 400/422 | 否 | 否 |
| 内容拦截 | 否 | 否 |

**熔断**：错误率 >30%/1min → 打开 30s → 半开。

---

## 11. 缓存

| 缓存 | 说明 |
|---|---|
| Prompt cache | Provider 前缀缓存 |
| 响应缓存 | 相同请求（谨慎） |
| 能力缓存 | 模型能力 |
| 配置缓存 | llm_config |

**响应缓存风险**：个性化/权限/时效；默认不做，除非严格 key + TTL。

## 13. 代码骨架

```python
async def chat(req, ctx):
    cfg = await configs.get(req.llm_config_id, ctx.tenant)
    caps = registry.capabilities(cfg.provider, cfg.model)
    validate(req, caps)
    decision = await quota.admit(cfg.pool_id, estimate(req), ctx)
    if not decision.ok: raise QuotaExceeded(decision.reset_at)
    adapter = registry.adapter(cfg.provider, cfg)
    try:
        async for chunk in adapter.chat(req):
            if chunk.usage: await usage.record(cfg, req, chunk.usage)
            yield normalize(chunk)
    except RetryableError:
        async for chunk in fallback(cfg, req): yield chunk
```
