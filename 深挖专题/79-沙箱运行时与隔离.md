# 79 沙箱运行时与隔离

## 1. 目标

- 让 Agent 能安全执行代码/命令/测试/Git。
- 不访问宿主、内网、其他用户数据。
- 快速创建/复用/回收，成本可控。
- 可观测、可审计、可演练。

---

## 2. 技术选型

| 方案 | 隔离 | 启动 | 运维 | 建议 |
|---|---|---|---|---|
| E2B/Firecracker | 强 | 快 | 中 | 推荐 |
| K8s + gVisor | 强 | 中 | 中 | 已有 K8s |
| K8s + Kata | 强 | 慢 | 中高 | 合规 |
| Docker | 弱 | 快 | 低 | 仅本地 |
| 托管沙箱 | 强 | 快 | 低 | 快速验证 |

**红线**：Docker 不能作为多租户安全边界。

---

## 3. 架构

```
API/Worker
  ↓
Sandbox Manager
  ├─ 配置/模板
  ├─ 创建/复用/暂停/销毁
  ├─ 预热池/共享池
  ├─ Git 租约
  ├─ LLM 代理
  └─ 事件/日志
  ↓
E2B/Firecracker 节点池
  ↓
沙箱 VM（独立内核/网络/文件）
```

---

## 4. 模板

| 模板 | 内容 |
|---|---|
| base | Python/Node/Git |
| data | pandas/numpy/duckdb |
| coding | claude/codex/pi CLI |
| custom | 业务依赖 |

**构建**
- 最小化镜像；固定 digest；签名。
- 预装常用依赖；避免运行时下载。
- 版本化；灰度；回滚。

---

## 5. 生命周期

```
request → lazy/prewarm → provisioning → running
→ idle → paused → deleted
→ error → failed
```

- lazy：首次创建。
- prewarm：池取。
- 空闲暂停；暂停后销毁。
- reconcile 清理孤儿。
- 重置可预览影响。

---

## 6. 隔离

| 层 | 控制 |
|---|---|
| 计算 | microVM/用户态内核 |
| 网络 | 默认拒绝；出站白名单 |
| 文件 | 独立工作目录；只读根 |
| 进程 | 限额/命名空间 |
| 设备 | 禁挂载 |
| 元数据 | 禁 169.254.169.254 |
| K8s | 禁 API |
| 账号 | 独立节点池/账号 |

---

## 7. 网络

- 默认无公网。
- 白名单：模型代理、Git、包管理（可选）。
- DNS 限制；防 DNS 重绑定。
- 禁内网网段；禁元数据。
- 出站代理审计。

---

## 8. 文件与 Git

### 8.1 文件

- 独立工作目录；任务后清理。
- 上传/下载走平台签名 URL。
- 不挂载宿主敏感目录。
- 大文件限制。

### 8.2 Git

| 模式 | 说明 |
|---|---|
| caller | 调用方 token（短期） |
| platform | 平台编码账号签发项目 token |
| fallback | platform 失败回退 caller |

- 项目白名单；租约 TTL；回收。
- 不暴露主 PAT。
- MR 模式：platform/skill。

---

## 9. 任务

```json
{
  "session_id": "s1",
  "command": "pytest -q",
  "kind": "shell|coding|generic",
  "cli": "claude|codex|pi|",
  "access_mode": "write|read",
  "timeout_seconds": 600,
  "cwd": "/workspace"
}
```

- 异步；事件/日志；取消。
- 超时 kill；资源限额。
- 回调签名。

---

## 10. 安全

| 风险 | 控制 |
|---|---|
| 逃逸 | microVM/补丁/演练 |
| SSRF | 网络白名单 |
| 数据外泄 | 无长期密钥/代理 |
| 挖矿 | CPU/网络异常检测 |
| 供应链 | 镜像签名/扫描 |
| 滥用 | 并发/时长/配额 |
| 持久化 | 任务后销毁 |

---

## 11. 成本

```
并发 = 日任务数 × 平均时长 / 86400 × 峰值
节点 = 并发 × 单沙箱资源 / 节点资源 / 0.7
预热 = 峰值 × 10–20%
```

- lazy/暂停/共享池/自动扩缩。
- 模板瘦身/预拉取。
- 成本按用户/Agent 归因。

---

## 12. 失败模式

| 失败 | 行为 |
|---|---|
| 创建失败 | 重试/降级只读 |
| 节点不足 | 排队/扩容 |
| 任务超时 | kill |
| Git 失败 | fallback/提示 |
| 代理失败 | 403/提示 |
| 逃逸 | 批量 kill/隔离/补丁 |

---

## 13. 可观测

| 指标 | 说明 |
|---|---|
| 创建成功率/耗时 | 健康 |
| 运行/暂停/失败 | 容量 |
| 任务成功率/耗时 | 质量 |
| 资源使用 | 成本 |
| 回收/孤儿 | 治理 |
| 异常网络/CPU | 安全 |

---

## 14. 实施顺序

1. 沙箱配置/模板/创建。
2. 生命周期/TTL/回收。
3. 任务/日志/取消。
4. 网络隔离/白名单。
5. Git 租约/LLM 代理。
6. 预热/共享池。
7. 安全演练/成本优化。
