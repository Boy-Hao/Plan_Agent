# 80 多租户与 SaaS 隔离

## 1. 何时需要

- 集团多子公司/事业部；
- 对外 SaaS；
- 私有化多客户；
- 合规要求数据隔离。

**建议**：首版可单租户，但所有表/缓存/OSS/日志预留 `tenant_id`，避免二次改造。

---

## 2. 隔离级别

| 级别 | 隔离 | 成本 | 适用 |
|---|---|---|---|
| L1 共享库共享表 | tenant_id | 低 | 小租户 |
| L2 共享库独立 schema | schema | 中 | 中大型 |
| L3 独立库 | DB | 高 | 大客户 |
| L4 独立部署 | 集群 | 最高 | 私有化 |

**演进**：L1 → 大租户迁 L2/L3；不要一开始全 L3。

---

## 3. 租户解析

```
域名 / Token claim / Header / 路径
→ TenantContext
→ 全链路传播
```

- 禁止从 body/query 接收 tenant_id（除超管）。
- Bot/回调按 bot_id 查租户。
- 登录后 JWT 带 tenant_id。
- 跨租户操作需显式授权 + 审计。

---

## 4. 数据隔离

- 所有业务表带 `tenant_id`；索引前缀。
- Repository 默认过滤；裸 SQL 禁止。
- 逻辑唯一带租户。
- 分区/分库按租户。
- 数据导出/删除按租户。

---

## 5. 缓存/对象/队列

| 层 | 隔离 |
|---|---|
| Redis | `t:{tenant}:...` |
| OSS | `/{tenant}/...` |
| 队列 | 按租户分区/路由 |
| 搜索/向量 | collection/partition/prefix |
| 日志/指标 | tenant_id 标签 |

---

## 6. 配额与计费

| 配额 | 说明 |
|---|---|
| 用户数 | 套餐 |
| Agent 数 | 套餐 |
| 消息/token | 月/日 |
| 并发 | 会话/沙箱 |
| 存储 | GB |
| 渠道数 | Bot |

- 超限限流/提示/升级。
- 用量按租户聚合；账单/发票。
- 预算告警。

---

## 7. 上下线

### 7.1 开通

```
申请 → 审批 → 创建租户 → 初始化角色/配额
→ 绑定 SSO/域名 → 邀请管理员 → 试用
```

### 7.2 停用

- 停止登录/API；保留数据 N 天。
- 导出/删除；审计。

### 7.3 迁移

- 租户从 L1 迁 L3：导出/导入/校验/切流量。
- 域名/SSO 变更。

---

## 8. 噪音邻居

| 问题 | 对策 |
|---|---|
| 单租户打爆模型 | 配额池/隔离池 |
| 单租户占满沙箱 | 并发限制/独立池 |
| 大租户拖慢 DB | 分库/只读副本/限流 |
| 大文件占满 OSS | 配额/生命周期 |
| 队列积压 | 按租户队列/优先级 |

---

## 9. 安全与合规

- 跨租户 0 成功（测试）。
- 密钥/数据/日志隔离。
- 数据驻留（区域）。
- 删除/导出（GDPR/合规）。
- 审计（谁访问了哪个租户）。
- 渗透测试。

---

## 10. 计费

| 模式 | 说明 |
|---|---|
| 订阅 | 月/年 |
| 用量 | token/消息/存储 |
| 混合 | 基础 + 超额 |
| 内部结算 | 部门分摊 |

- 计量准确；对账；发票。
- 试用/优惠/欠费停服。

---

## 11. 运维

- 租户健康看板。
- 配额/成本告警。
- 大租户专属支持。
- 版本灰度按租户。

---

## 12. 失败模式

| 失败 | 行为 |
|---|---|
| 租户解析失败 | 拒绝 |
| 跨租户 | 403/404 + 告警 |
| 配额超 | 限流/提示 |
| 大租户故障 | 隔离/降级 |
| 数据迁移失败 | 回滚 |

---

## 13. 实施顺序

1. tenant_id + 中间件 + 测试。
2. 缓存/OSS/日志前缀。
3. 配额/用量。
4. 租户管理/开通。
5. 计费（如 SaaS）。
6. 大租户隔离/迁移。
7. 合规/审计。

---

## 14. 验收标准

- [ ] 跨租户 0 成功。
- [ ] 所有层带租户隔离。
- [ ] 配额/计费准确。
- [ ] 开通/停用/迁移可执行。
- [ ] 噪音邻居有隔离。
- [ ] 数据导出/删除合规。
