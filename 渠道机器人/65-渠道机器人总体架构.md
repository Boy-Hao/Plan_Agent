# 65 渠道机器人总体架构

## 1. 目标

- 一个平台连接 N 个 App 的机器人。
- 渠道差异隔离在适配器，核心只处理统一消息。
- 支持私聊/群聊/线程/引用/媒体/卡片/流式（按能力）。
- 身份、权限、租户、配额、审计与 Web 端一致。

---

## 2. 分层

```
Channel Apps
  │ webhook / WS / polling
  ▼
Bot Gateway（验签/解析/去重/归一化）
  ▼
Bot Router（身份/绑定/会话/路由）
  ▼
Agent Runtime（SSE）
  ▼
Channel Renderer（文本/卡片/分片/降级）
  ▼
Channel Adapter（发送/更新/撤回/媒体）
  ▼
Channel Apps
```

**原则**：Gateway 不写业务；Router 不碰渠道 SDK；Adapter 不做权限决策。

---

## 3. 领域模型

| 实体 | 关键字段 | 说明 |
|---|---|---|
| `bot_config` | bot_id, tenant_id, channel, name, credentials_cipher, webhook_secret, enabled, owner_id | 一个 App 机器人 |
| `bot_agent_binding` | id, bot_id, agent_id, priority, match_type, match_value, default | Bot→Agent 路由 |
| `external_identity` | id, tenant_id, channel, bot_id, external_user_id, union_id, platform_user_id, status | 外部身份映射 |
| `bot_chat` | id, bot_id, channel_chat_id, chat_type, title, last_active_time | 外部会话 |
| `conversation_link` | id, bot_chat_id, platform_session_id, agent_id, status | 外部会话↔平台会话 |
| `message_map` | id, channel_message_id, platform_message_id, direction, status | 消息映射（编辑/撤回） |
| `delivery_log` | id, bot_id, message_id, status, attempts, error_code, latency_ms | 投递日志 |
| `bot_health` | bot_id, status, last_ok, last_error, ws_status | 健康 |

**索引**：`(tenant_id, channel, bot_id)`、`(external_user_id, bot_id)`、`(bot_chat_id)`。

---

## 4. 入站流程

```
1. 收到 webhook/WS 事件
2. 验签（签名/时间窗/nonce）
3. 去重（event_id/message_id）
4. 解析为统一 InboundMessage
5. 识别租户/Bot/渠道
6. 身份映射（绑定/游客/拒绝）
7. 路由到 Agent（绑定/命令/关键词/默认）
8. 获取/创建平台会话
9. 调 Runtime（流式或阻塞）
10. 渲染并发送回复
11. 记录投递/指标/审计
```

  "event_id": "evt_1",

## 5. 身份映射

| 场景 | 策略 |
|---|---|
| 已绑定 | 直接用 platform_user_id |
| 未绑定（私聊） | 引导绑定（bind_nonce/link） |
| 未绑定（群聊） | 游客/只读/提示绑定 |
| 外部系统用户 | 通过 union_id/email/手机号匹配 |
| 多租户 | Bot 固定租户；跨租户需显式配置 |

**规则**
- 外部 ID 不可直接当平台用户 ID。
- 绑定关系加密/审计；可解绑。
- 群聊里不同用户身份要区分（@/sender）。
- 游客模式要限权/限配额。

---

## 6. 路由

```
Bot → Agent
  ├─ 命令（/agent xxx）
  ├─ 关键词/正则
  ├─ 群/频道绑定
  ├─ 默认 Agent
  └─ 优先级/回退
```

- 一个 Bot 可绑多个 Agent（按场景/群）。
- 路由冲突按 priority；无匹配用 default。
- 路由变更清缓存；审计。
- 群聊可配置「仅 @机器人」触发。

---

## 7. 会话映射

| 外部 | 平台 |
|---|---|
| 私聊 | 一个 `bot_chat` ↔ 一个 `session` |
| 群聊 | 一个群 ↔ 一个 session（或每用户一个） |
| 线程 | 线程 ↔ session（推荐） |
| 定时/推送 | 不建 session，直接发 |

**策略可配**：
- `per_chat`：群共享上下文（需注意隐私）。
- `per_user`：群内每用户独立（推荐）。
- `per_thread`：线程独立。

## 8. 出站与渲染

### 8.1 能力标志

```python
@dataclass
class ChannelCapabilities:
    streaming: bool
    edit_message: bool
    cards: bool
    markdown: bool
    media: bool
    threads: bool
    mentions: bool
    reactions: bool
    read_receipts: bool
    recall: bool
    max_text_len: int
```

### 8.2 渲染策略

| 内容 | 渲染 |
|---|---|
| 文本 | 分片/转义 |
| Markdown | 原生/转纯文本 |
| 卡片 | 平台卡片→渠道卡片 |
| 代码 | 代码块/附件 |
| 图片/文件 | 上传/链接 |
| 长文本 | 分片/摘要/附件 |
| 流式 | 编辑消息/卡片更新/打字态 |
| 不支持流式 | 先「正在处理」，完成后发最终 |

**降级顺序**：卡片 → Markdown → 纯文本 → 摘要 + 链接。

---

## 9. 流式

| 渠道能力 | 策略 |
|---|---|
| 可编辑消息 | 节流更新（1–2s/次） |
| 卡片更新 | 增量更新卡片 |
| 仅发送 | 先发「处理中」，完成发最终 |
| 有打字态 | 显示 typing |
| 限频 | 合并/降低更新频率 |

**注意**：平台有速率限制；不要每 token 更新；失败回退到最终消息。

## 10. 可靠性

| 机制 | 说明 |
|---|---|
| 验签 | 签名/时间窗/nonce |
| 去重 | event_id/message_id |
| 幂等 | 发送/更新幂等 |
| 重试 | 指数退避；仅可重试错误 |
| 队列 | 入站/出站解耦 |
| 限流 | 按 Bot/渠道/用户 |
| 熔断 | 渠道故障 |
| 死信 | 人工重放 |
| 顺序 | 同会话串行 |

---

## 11. 安全

| 风险 | 控制 |
|---|---|
| 伪造回调 | 验签/时间窗/nonce |
| 重放 | 去重/短 TTL |
| 密钥泄露 | 加密/掩码/轮换 |
| 越权 | 身份绑定/权限/租户 |
| SSRF | 回调/媒体 URL 白名单 |
| 内容安全 | 审核/脱敏 |
| 滥用 | 限流/配额 |
| 群聊隐私 | per_user 上下文/提示 |

---

## 12. 多租户与多 Bot

- 每个 Bot 固定租户；跨租户需显式授权。
- 同一渠道可有多个 Bot（不同应用/品牌）。
- 配额按 Bot/租户/用户。
- 管理端按租户隔离；超管可跨租户。
- 密钥/回调/日志带租户。

---

## 13. 部署

| 组件 | 部署 |
|---|---|
| Bot Gateway | 无状态多副本（webhook） |
| WS Workers | 有状态，按 Bot 分片/租约 |
| Outbound Worker | 队列消费，按渠道限流 |
| Renderer | 无状态 |
| Redis | 去重/限流/会话映射/健康 |
| DB | 配置/身份/日志 |

**Webhook**：统一入口 `/api/bots/{channel}/callback/{bot_id}`；验签后入队。
**WS**：每 Bot 单活跃连接；租约/故障转移。

**日志**：bot_id/channel/chat_id/message_id/trace_id；不记录密钥/正文全文。

## 15. 容量

```
入站 QPS = 日活 × 人均消息 / 86400 × 峰值系数
出站 QPS = 入站 × 平均回复条数
WS 连接 = Bot 数 × 副本冗余
```

- 出站按渠道限流；队列削峰。
- 大 Bot 独立队列/限流。
- 媒体上传走 OSS/异步。

## 16. 验收标准

- [ ] 一个 Bot 可绑定多 Agent/租户。
- [ ] 身份绑定/游客/群聊策略可用。
- [ ] 文本/图片/文件/引用收发。
- [ ] 流式或降级明确。
- [ ] 验签/去重/重试/限流。
- [ ] 新增渠道只加适配器。
- [ ] 管理端可配置/健康/日志。
- [ ] 渠道故障不影响核心对话。
