# 66 渠道接入配置手册

> 每个渠道按统一模板写：**准备 → 创建应用 → 配置回调/权限 → 平台登记 → 绑定 Agent → 测试 → 上线**。
> 具体 API 名称/权限以各平台官方文档为准；本文给的是接入路径与坑位。

---

## 1. 飞书（Feishu/Lark）

### 1.1 准备

- 企业管理员权限。
- 自建应用（企业内）。
- 公网 HTTPS 或长连接（推荐 WS）。

### 1.2 创建应用

1. 开放平台 → 创建企业自建应用。
2. 获取 `app_id` / `app_secret`。
3. 开启机器人能力。
4. 配置权限：发消息、读消息、群信息、文件、卡片。
5. 事件订阅：`im.message.receive_v1` 等。
6. 配置回调/长连接；获取 `encrypt_key`、`verification_token`。

### 1.3 平台登记

- 渠道：feishu。
- 填 app_id/secret/encrypt_key/verification_token。
- 模式：WS 或 Webhook。
- 绑定 Agent；开启对话。

### 1.4 测试

- 私聊发「你好」→ 流式/卡片回复。
- 群聊 @机器人 → 回复。
- 图片/文件 → 解析。
- 未绑定用户 → 引导绑定。

### 1.5 坑位

- WS 只允许一个活跃连接；多副本要租约。
- 卡片更新有频率限制；节流。
- 事件重复投递；按 event_id 去重。
- 权限不足/未发布版本 → 收不到事件。

## 2. 企业微信（WeCom）

### 2.1 准备

- 企业微信管理后台。
- 自建应用/智能机器人。
- 可信域名/公网回调。

### 2.2 配置

1. 创建自建应用，获取 `corp_id`、`agent_id`、`secret`。
2. 配置接收消息服务器 URL、Token、EncodingAESKey。
3. 配置可信域名/IP 白名单。
4. 权限：发消息、通讯录、媒体。

### 2.3 平台登记

- 渠道：wecom。
- 填 corp_id/agent_id/secret/token/aes_key。
- Webhook 模式。

### 2.4 测试

- 私聊/群聊 @。
- 文本/图片/文件。
- 模板卡片（如支持）。

### 2.5 坑位

- 回调需 URL 验证（echostr）。
- 消息加密（AES）；验签。
- 主动推送有频率/范围限制。
- 可信域名未配置 → 回调失败。

## 3. 钉钉（DingTalk）

### 3.1 准备

- 钉钉开放平台 → 企业内部应用。
- 机器人能力。

### 3.2 配置

1. 创建应用，获取 `AppKey`/`AppSecret`。
2. 开启机器人；配置消息接收模式（Webhook/Stream）。
3. 配置加签 `sign`/`token`/`aes_key`。
4. 权限：发消息、群会话、媒体。

### 3.3 平台登记

- 渠道：dingtalk。
- 填 AppKey/AppSecret/robotCode/token/aes_key。
- 模式：Webhook 或 Stream。

### 3.4 测试

- 单聊/群聊 @。
- ActionCard/Markdown。
- 图片/文件。

### 3.5 坑位

- 加签时间戳；重放。
- Stream 模式需要长连接。
- 群机器人 vs 企业内部机器人能力不同。

---

## 4. Slack

### 4.1 准备

- Slack App（OAuth）。
- 公网 HTTPS。

### 4.2 配置

1. 创建 App；Bot Token Scopes：`chat:write`、`channels:history`、`files:read` 等。
2. Event Subscriptions：`message.channels`、`app_mention`。
3. Request URL 验签（Signing Secret）。
4. OAuth 安装到 workspace。

### 4.3 平台登记

- 渠道：slack。
- 填 client_id/secret/signing_secret/bot_token。
- 绑定 Agent。

### 4.4 测试

- DM/频道 @。
- Block Kit 卡片。
- 线程回复。

### 4.5 坑位

- 3 秒内响应 URL 验证/事件；异步处理。
- 重试带 `X-Slack-Retry-Num`；去重。
- 速率限制（Tier）。

---

## 5. Microsoft Teams

### 5.1 准备

- Azure Bot Service。
- Teams App Manifest。
- 公网 HTTPS。

### 5.2 配置

1. 注册 Azure Bot；获取 Microsoft App ID/Password。
2. 配置 Messaging Endpoint。
3. Teams 频道/应用安装。
4. 权限：消息、团队、文件。

### 5.3 平台登记

- 渠道：teams。
- 填 app_id/password/tenant_id。
- 绑定 Agent。

### 5.4 测试

- 个人/团队/频道。
- Adaptive Card。
- 文件。

### 5.5 坑位

- Bot Framework 认证（JWT）。
- 会话引用（conversation reference）需保存。
- 主动消息需 conversation reference。

## 6. Discord

### 6.1 准备

- Discord Developer Portal。
- Bot Token。
- Gateway Intents。

### 6.2 配置

1. 创建 Application/Bot；获取 token。
2. 开启 Message Content Intent（如需）。
3. 邀请 Bot 到服务器。
4. 配置命令/事件。

### 6.3 平台登记

- 渠道：discord。
- 填 bot_token/public_key。
- 绑定 Agent。

### 6.4 测试

- DM/频道 @。
- Embed/按钮。
- 附件。

### 6.5 坑位

- Gateway 长连接/重连。
- 交互回调 3 秒。
- 速率限制严格。

## 7. Telegram

### 7.1 准备

- BotFather 创建 Bot。
- Token。

### 7.2 配置

1. 获取 token。
2. 设置 webhook 或 long polling。
3. 命令/隐私模式。

### 7.3 平台登记

- 渠道：telegram。
- 填 token/secret_token。
- 绑定 Agent。

### 7.4 测试

- 私聊/群/频道。
- 编辑消息（流式）。
- 图片/文件。

### 7.5 坑位

- Webhook 需 HTTPS/证书。
- 群隐私模式需 @。
- 编辑消息频率。

## 8. 微信公众号 / 客服

### 8.1 准备

- 认证公众号/服务号。
- 服务器配置（URL/Token/EncodingAESKey）。

### 8.2 配置

1. 基本配置 → 服务器配置。
2. 验证 URL。
3. 权限：消息、素材、模板。
4. 48 小时客服消息窗口。

### 8.3 平台登记

- 渠道：wechat_mp。
- 填 app_id/secret/token/aes_key。
- 绑定 Agent。

### 8.4 测试

- 文本/图片/语音。
- 图文/模板消息。

### 8.5 坑位

- 5 秒响应；异步。
- 被动回复 XML。
- 48 小时限制。

## 9. 邮件

### 9.1 准备

- 专用邮箱/IMAP/SMTP。
- 应用专用密码。

### 9.2 配置

1. IMAP 收件（轮询/IDLE）。
2. SMTP 发件。
3. SPF/DKIM/DMARC。
4. 主题/引用解析。

### 9.3 平台登记

- 渠道：email。
- 填 IMAP/SMTP/账号/密码。
- 绑定 Agent。

### 9.4 测试

- 收邮件→回复。
- HTML/附件。
- 线程（In-Reply-To）。

### 9.5 坑位

- 垃圾邮件/退信。
- 附件大小。
- 发件频率/声誉。

---

## 10. Web 组件 / 自定义

### 10.1 Web Widget

- 平台提供 JS SDK/iframe。
- WebSocket/SSE 流式。
- 匿名/登录态。
- 主题/位置/欢迎语。

### 10.2 自定义 Webhook

- 入站：`POST /api/bots/custom/callback/{bot_id}`。
- 出站：配置 URL/签名。
- 统一 envelope（见 65）。
- 适合内部系统/自研 App。

## 12. 上线顺序建议

1. 飞书（验证抽象）。
2. 企业微信/钉钉（国内企业）。
3. Slack/Teams（海外企业）。
4. Discord/Telegram（社区）。
5. 微信/邮件/Web/自定义（长尾）。
