# 67 新增渠道适配器开发指南

> 目标：新增一个 App 机器人，只写适配器，不改 Gateway/Router/Runtime。
> 适配器负责：验签、解析、发送、更新、媒体、能力声明、健康检查。

---

## 1. 适配器接口

```python
from typing import Protocol, AsyncIterator

class ChannelAdapter(Protocol):
    channel: str

    def capabilities(self) -> ChannelCapabilities: ...

    async def verify(self, request: RawRequest) -> bool: ...

    async def parse(self, request: RawRequest) -> list[InboundMessage]: ...

    async def send_text(self, chat_id: str, text: str, reply_to: str | None = None) -> SendResult: ...

    async def send_card(self, chat_id: str, card: dict, reply_to: str | None = None) -> SendResult: ...

    async def update_message(self, message_id: str, text: str | None = None, card: dict | None = None) -> SendResult: ...

    async def send_media(self, chat_id: str, file: MediaRef, caption: str = "") -> SendResult: ...

    async def recall(self, message_id: str) -> bool: ...

    async def health(self) -> HealthResult: ...
```

**可选能力**：`typing`、`reaction`、`thread_reply`、`read_receipt`。
不支持就抛 `NotSupported`，由 Renderer 降级。

## 2. 能力声明

```python
@dataclass(frozen=True)
class ChannelCapabilities:
    streaming: bool
    edit_message: bool
    cards: bool
    markdown: bool
    media: bool
    threads: bool
    mentions: bool
    reactions: bool
    read_receipts: bool
    recall: bool
    max_text_len: int
    max_card_bytes: int
    rate_limit_per_sec: float
```

**用途**：Renderer 根据能力选择「流式编辑/最终发送/分片/卡片/纯文本」。

## 4. 验签

| 模式 | 做法 |
|---|---|
| HMAC | `HMAC(secret, timestamp + nonce + body)` |
| 平台签名 | 按官方算法（如飞书/钉钉） |
| 时间窗 | ±5min |
| 重放 | nonce/event_id 去重 |
| 加密 | AES 解密（如企微） |

**要求**：验签失败 401；不泄露细节；记录 bot_id/来源 IP。

---

## 5. 解析

- 文本/富文本/卡片/图片/文件/语音/视频。
- @机器人/引用/线程。
- 群聊 sender 与 chat 区分。
- 事件类型（消息/加入/菜单/按钮回调）。
- 去重键：`event_id`/`message_id`。

**原则**：Adapter 只做「平台格式 → 统一格式」，不做权限/路由。

---

## 6. 发送与更新

### 6.1 文本

- 分片（`max_text_len`）。
- Markdown → 平台格式（支持则保留，不支持转纯文本）。
- 转义（避免注入平台标记）。

### 6.2 卡片

- 平台卡片模板 → 统一卡片模型 → 平台卡片。
- 不支持卡片 → Markdown/文本。
- 卡片更新节流（1–2s）。

### 6.3 媒体

- 先上传（平台要求）→ 发消息。
- 大小/类型限制；失败降级为链接。
- 图片压缩/缩略图。

### 6.4 流式

- 可编辑：节流更新；结束发最终。
- 不可编辑：先「处理中」→ 最终。
- 失败：回退最终消息。

---

## 7. 限流与重试

| 错误 | 处理 |
|---|---|
| 429 | 读 Retry-After；退避 |
| 5xx | 重试 1–2 次 |
| 4xx | 不重试；记录 |
| 超时 | 重试/降级 |
| Token 过期 | 刷新/告警 |

- 按渠道/Bot/聊天限流。
- 出站队列削峰。
- 幂等键防重复发送。

## 9. 代码骨架

```python
class CustomAdapter:
    channel = "custom"

    def __init__(self, config: BotConfig, http: HttpClient):
        self.config = config
        self.http = http

    def capabilities(self):
        return ChannelCapabilities(
            streaming=True, edit_message=True, cards=False,
            markdown=True, media=True, threads=False, mentions=True,
            reactions=False, read_receipts=False, recall=False,
            max_text_len=4000, max_card_bytes=0, rate_limit_per_sec=10,
        )

    async def verify(self, req):
        sig = req.headers.get("X-Signature", "")
        ts = req.headers.get("X-Timestamp", "")
        if abs(time.time() - int(ts)) > 300: return False
        expected = hmac_sha256(self.config.secret, f"{ts}\n{req.body}")
        return hmac.compare_digest(sig, expected)

    async def parse(self, req):
        data = json.loads(req.body)
        return [InboundMessage(
            channel=self.channel, bot_id=self.config.bot_id,
            tenant_id=self.config.tenant_id,
            event_id=data["event_id"], message_id=data["message_id"],
            chat_id=data["chat_id"], chat_type=data.get("chat_type","direct"),
            sender=Sender(external_user_id=data["user_id"], name=data.get("user_name")),
            text=data.get("text",""), raw=data,
        )]

    async def send_text(self, chat_id, text, reply_to=None):
        resp = await self.http.post(self.config.api_base + "/messages", json={
            "chat_id": chat_id, "text": text, "reply_to": reply_to
        })
        return SendResult(message_id=resp["id"], ok=True)
```

## 10. 测试

### 10.1 单元

- 验签（正确/错误/过期/重放）。
- 解析（文本/图片/文件/群聊/@/引用）。
- 分片/转义。
- 能力降级。

### 10.2 契约

- 用录制 fixture 回放平台请求。
- 断言统一消息字段。
- 发送请求 body 符合平台 API。

### 10.3 集成

- 沙箱环境真实 Bot。
- 私聊/群聊/媒体/卡片。
- 限流/重试/断线。

### 10.4 一致性测试（Conformance）

所有适配器跑同一套用例：

- 验签失败 401。
- 重复事件只处理一次。
- 超长文本分片。
- 不支持卡片时降级。
- 发送失败重试。
- 健康检查。

## 11. 新增渠道步骤

1. 实现 Adapter + 能力声明。
2. 注册到 `ADAPTER_REGISTRY`。
3. 管理端表单 schema（字段/校验）。
4. 回调路由（webhook）或 WS worker。
5. 渲染映射（文本/卡片/媒体）。
6. 身份字段映射（external_user_id/union_id/email）。
7. 测试 fixture + conformance。
8. 文档（66 增加一节）。
9. 灰度/上线。
