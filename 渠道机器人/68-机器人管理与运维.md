# 68 机器人管理与运维

## 1. 管理端功能

| 功能 | 说明 |
|---|---|
| Bot 列表 | 渠道/状态/最后活跃/错误 |
| 新建/编辑 | 渠道/凭证/回调/模式 |
| 绑定 Agent | 多 Agent/优先级/默认 |
| 能力展示 | 流式/卡片/媒体/线程 |
| 测试连接 | 验签/发消息/收消息 |
| 健康状态 | Webhook/WS/最后错误 |
| 日志 | 入站/出站/错误/重试 |
| 配额/限流 | 按 Bot/租户/用户 |
| 密钥轮换 | 新旧过渡/失效 |
| 启停/删除 | 影响预览 |

---

## 2. 配置生命周期

```
draft → tested → enabled → disabled → deleted
```

| 状态 | 行为 |
|---|---|
| draft | 不接流量 |
| tested | 测试通过 |
| enabled | 接收/发送 |
| disabled | 停止接流量；保留配置 |
| deleted | 软删；解绑；审计 |

**变更**：凭证/回调/绑定变更需审计；影响预览；可回滚。

---

## 3. 凭证管理

- 加密存储；掩码回显。
- 轮换：新凭证生效 → 观察 → 旧凭证失效。
- 泄露：立即轮换 + 停用 + 排查。
- 不同环境/租户隔离。
- 日志不记录凭证。

---

## 4. 健康与指标

| 指标 | 说明 |
|---|---|
| 入站/出站量 | 按渠道/Bot |
| 验签失败 | 安全 |
| 去重率 | 质量 |
| 身份绑定率 | 采用 |
| 首响/完整延迟 | 体验 |
| 发送失败/重试 | 稳定 |
| 限流/熔断 | 容量 |
| WS 重连 | 健康 |

**健康状态**
- Webhook：最近 200/失败。
- WS：connected/disconnected/reconnecting。
- 最后成功/失败时间；错误码。

---

## 5. 告警

| 级别 | 条件 |
|---|---|
| P1 | Bot 连续 5min 收不到消息/发送失败>20% |
| P2 | 验签失败突增/重试>10%/限流 |
| P3 | 单用户/单群异常 |

**要求**：告警带 bot_id/channel/错误；有 Runbook。

---

## 6. 排障手册

### 6.1 收不到消息

1. 应用是否发布/安装。
2. 回调 URL 是否可达/证书。
3. 验签/加解密是否正确。
4. 事件订阅是否包含消息事件。
5. 权限/Scopes。
6. 平台是否限流/停用。
7. 日志/抓包。

### 6.2 发不出消息

1. Token 是否过期。
2. 权限/范围。
3. 用户/群是否可达。
4. 内容是否违规/超长。
5. 限流/频率。
6. 平台 API 错误码。

### 6.3 重复消息

1. 平台重试。
2. 去重键是否生效。
3. 队列重复消费。
4. 多副本同时处理。

### 6.4 流式不更新

1. 渠道是否支持编辑/卡片。
2. 更新频率是否被限。
3. 消息 ID 是否正确。
4. 失败是否回退最终。

### 6.5 身份绑定失败

1. external_user_id/union_id 映射。
2. 绑定流程是否完成。
3. 租户/权限。
4. 多账号冲突。

### 6.6 WS 断连

1. 单活跃连接租约。
2. 网络/代理。
3. 重连退避。
4. 凭证/权限。

---

## 7. 多租户与配额

- Bot 固定租户；跨租户需授权。
- 配额：消息数/用户数/并发。
- 大 Bot 独立队列/限流。
- 管理端按租户隔离；超管跨租户。

---

## 8. 发布与变更

| 变更 | 风险 | 做法 |
|---|---|---|
| 新增 Bot | 低 | 测试→灰度 |
| 凭证轮换 | 中 | 双版本过渡 |
| 回调变更 | 中 | 验证→切换 |
| 绑定 Agent | 中 | 影响预览 |
| 渠道升级 | 高 | 灰度/回滚 |

---

## 9. Runbook 模板

```
【Bot】channel/bot_id
【现象】收不到/发不出/重复/慢
【影响】用户/群/租户
【检查】应用状态/回调/验签/权限/限流/日志
【止损】停用/切备用/降级文本
【恢复】修复配置/重连/轮换
【验证】私聊/群聊/媒体
【复盘】根因/改进
```

---

## 10. 验收标准

- [ ] 管理端可配置/测试/启停/删除。
- [ ] 凭证加密/轮换/审计。
- [ ] 健康/指标/告警可用。
- [ ] 排障手册覆盖高频问题。
- [ ] 多租户/配额隔离。
- [ ] 变更可灰度/回滚。
- [ ] 渠道故障不影响核心对话。
