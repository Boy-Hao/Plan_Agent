# 70 机器人安全与多租户

## 1. 威胁模型

| 威胁 | 场景 | 对策 |
|---|---|---|
| 伪造回调 | 攻击者 POST 假消息 | 验签/时间窗/nonce |
| 重放 | 重复投递 | event_id 去重/短 TTL |
| 凭证泄露 | secret 落日志/前端 | 加密/掩码/轮换 |
| 跨租户 | Bot A 读租户 B | tenant 绑定/校验 |
| 身份冒用 | 伪造 open_id | 平台签名/绑定 |
| SSRF | 媒体/回调 URL 内网 | 白名单/禁内网 |
| 内容攻击 | Prompt 注入/钓鱼 | 分隔/审核/权限 |
| 滥用 | 刷消息/大文件 | 限流/配额/大小 |
| 群聊泄露 | 群共享上下文 | per_user/提示 |

---

## 2. 验签

### 2.1 通用

```
signature = HMAC-SHA256(secret, timestamp + "\n" + nonce + "\n" + body)
```

- 时间窗 ±5min。
- nonce/event_id 去重。
- 常量时间比较。
- 失败 401，不泄露细节。

### 2.2 平台差异

| 渠道 | 方式 |
|---|---|
| 飞书 | Encrypt Key/Verification Token/签名 |
| 企微 | Token/EncodingAESKey/签名 |
| 钉钉 | 加签/token/aes_key |
| Slack | Signing Secret |
| Teams | Bot Framework JWT |
| Discord | Public Key/Ed25519 |
| Telegram | Secret Token |
| 微信 | Token/签名 |

**实现**：每个 Adapter 自己验签；Gateway 只调用 `verify()`。

---

## 3. 身份安全

- 外部 ID 不可直接当平台用户。
- 绑定需平台登录态 + 一次性 nonce。
- 绑定关系可解绑/审计。
- 群聊区分 sender 与 chat。
- 游客模式限权/限配额。
- 防止「绑定劫持」：nonce 短 TTL、一次性、绑定到发起人。

---

## 4. 租户隔离

| 层 | 隔离 |
|---|---|
| Bot | `tenant_id` 固定 |
| DB | 所有表带 tenant_id |
| Redis | `t:{tenant}:bot:...` |
| 队列 | 按租户/Bot 分区 |
| OSS | `/{tenant}/bots/...` |
| 日志 | tenant_id/bot_id |
| 限流 | 按租户/Bot/用户 |
| 管理端 | 数据范围 |

**规则**：回调 URL 里的 bot_id 必须解析出租户；禁止跨租户复用 Bot；超管跨租户需审计。

---

## 5. 凭证管理

- 加密存储（KMS/Vault + AES-GCM）。
- 只在 Adapter 解密使用。
- 日志/错误不输出。
- 轮换：双版本过渡 → 旧失效。
- 泄露：停用 + 轮换 + 排查 + 通知。
- 不同环境/租户独立。

---

## 6. 内容安全

- 入站：文本/图片/文件审核；大小/类型。
- 出站：脱敏/审核；防钓鱼链接。
- Prompt 注入：外部内容标记为数据；工具白名单。
- 群聊：避免泄露他人上下文；per_user 默认。
- 敏感数据：按租户策略脱敏。

---

## 7. 滥用与配额

| 配额 | 说明 |
|---|---|
| 消息/分钟 | 按用户/群/Bot |
| 并发会话 | 按用户 |
| 附件大小 | 按渠道 |
| 日 token | 按用户/租户 |
| 绑定数 | 按用户 |

- 超限 429/提示。
- 大 Bot 独立队列。
- 异常行为告警（刷屏/大文件/高频绑定）。

---

## 8. 审计

| 事件 | 记录 |
|---|---|
| Bot 创建/更新/删除 | 操作人/前值/后值 |
| 凭证轮换 | 操作人/时间（不含值） |
| 绑定/解绑 | 用户/外部 ID |
| 启停/回调变更 | 操作人/影响 |
| 跨租户操作 | 原因/审批 |

- 保留 ≥1 年；导出脱敏。
- 高危操作可双人审批。

---

## 9. 事件响应

| 事件 | 动作 |
|---|---|
| 验签失败突增 | 限流/封禁来源/告警 |
| 凭证泄露 | 停用/轮换/排查 |
| 跨租户 | 停服/取证/通知 |
| 恶意内容 | 删除/封禁/审核 |
| 渠道被封 | 切换备用/通知 |

---

## 10. 验收标准

- [ ] 所有回调验签/时间窗/去重。
- [ ] 外部身份不能直接映射平台用户。
- [ ] 跨租户 0 成功。
- [ ] 凭证加密/轮换/不落日志。
- [ ] 内容审核/注入防护。
- [ ] 配额/限流生效。
- [ ] 高危操作审计/可导出。
