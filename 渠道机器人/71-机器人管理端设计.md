# 71 机器人管理端设计

## 1. 页面结构

```
渠道机器人
├─ Bot 列表
├─ 新建 Bot（向导）
├─ Bot 详情
│  ├─ 基础信息
│  ├─ 凭证/回调
│  ├─ Agent 绑定
│  ├─ 能力/模式
│  ├─ 健康
│  ├─ 日志
│  └─ 测试控制台
└─ 全局日志/告警
```

---

## 2. Bot 列表

| 列 | 说明 |
|---|---|
| 名称 | + 渠道图标 |
| 渠道 | feishu/wecom/... |
| 状态 | draft/tested/enabled/disabled |
| 模式 | webhook/ws/polling |
| 绑定 Agent | 数量/默认 |
| 健康 | 绿/黄/红 |
| 最后活跃 | 时间 |
| 操作 | 测试/启停/编辑/删除 |

**交互**：筛选（渠道/状态/关键词）、分页、批量启停、空态。

## 3. 新建向导

### Step 1：选择渠道

- 卡片：飞书/企微/钉钉/Slack/Teams/Discord/Telegram/微信/邮件/Web/自定义。
- 显示能力（流式/卡片/媒体）。

### Step 2：基础信息

- 名称、租户、负责人、描述。

### Step 3：凭证

按渠道动态表单：

| 渠道 | 字段 |
|---|---|
| 飞书 | app_id/app_secret/encrypt_key/verification_token |
| 企微 | corp_id/agent_id/secret/token/aes_key |
| 钉钉 | app_key/app_secret/robot_code/token/aes_key |
| Slack | client_id/secret/signing_secret/bot_token |
| Teams | app_id/password/tenant_id |
| Discord | bot_token/public_key |
| Telegram | token/secret_token |
| 微信 | app_id/secret/token/aes_key |
| 邮件 | imap/smtp/account/password |
| 自定义 | secret/callback |

- 密钥输入 `type=password`；保存后掩码。
- 轮换：新值输入，旧值失效提示。

### Step 4：回调/模式

- Webhook URL（自动生成，可复制）。
- WS/长连接开关。
- 验证按钮（发测试事件/握手）。

### Step 5：绑定 Agent

- 选择 Agent；设默认/优先级。
- 匹配类型：默认/命令/关键词/群。
- 影响提示（哪些群/用户会切换）。

### Step 6：测试

- 发送测试消息到指定用户/群。
- 显示请求/响应/延迟/错误。
- 通过后启用。

---

## 4. Bot 详情

### 4.1 基础

- 名称/渠道/租户/状态/模式。
- 最后活跃/健康/版本。

### 4.2 凭证

- 掩码展示。
- 轮换按钮 + 二次确认。
- 回调 URL + 复制。
- 验证状态。

### 4.3 Agent 绑定

- 表格：Agent/优先级/匹配/默认/启停。
- 拖拽排序。
- 冲突提示。
- 影响预览。

### 4.4 能力

- 流式/卡片/媒体/线程（只读，来自适配器）。
- 降级策略（自动/文本/链接）。

### 4.5 健康

- Webhook/WS 状态。
- 最近成功/失败/错误码。
- 入站/出站曲线。
- 重连按钮。

### 4.6 日志

- 入站/出站/错误/重试。
- 筛选：时间/方向/状态/用户/群。
- 详情：请求 ID、耗时、错误。
- 脱敏；不展示密钥/正文全文。

### 4.7 测试控制台

- 选择用户/群。
- 输入文本/媒体。
- 发送并查看结果。
- 模拟入站（可选）。

---

## 5. 状态与权限

| 状态 | 可操作 |
|---|---|
| draft | 编辑/测试/启用 |
| tested | 启用/编辑 |
| enabled | 停用/编辑/日志 |
| disabled | 启用/删除 |
| deleted | 只读/恢复（可选） |

**权限**：`bot:view` 查看；`bot:manage` 编辑/启停/轮换；超管跨租户。

---

## 6. 交互细节

- 密钥永不回显；只显示「已配置」。
- 危险操作二次确认 + 影响列表。
- 未保存离开提示。
- 测试失败给可行动建议（验签/权限/回调）。
- 空态引导（先创建应用/配置回调）。
- 错误码映射为中文提示。

## 7. API 映射

| 页面 | API |
|---|---|
| 列表 | `GET /admin/bots` |
| 新建 | `POST /admin/bots` |
| 详情 | `GET /admin/bots/{id}` |
| 更新 | `PUT /admin/bots/{id}` |
| 测试 | `POST /admin/bots/{id}/test` |
| 启停 | `PUT /admin/bots/{id}/enabled` |
| 绑定 | `GET/PUT /admin/bots/{id}/bindings` |
| 健康 | `GET /admin/bots/{id}/health` |
| 日志 | `GET /admin/bots/{id}/logs` |
| 轮换 | `POST /admin/bots/{id}/rotate-secret` |
