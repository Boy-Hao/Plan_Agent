# 72 机器人测试与上线清单

## 1. 测试矩阵

| 层 | 内容 | 工具 |
|---|---|---|
| 单元 | 验签/解析/分片/能力降级 | pytest/vitest |
| 契约 | 请求/响应/统一消息 | fixture/录制 |
| 集成 | 沙箱真实 Bot | 测试企业应用 |
| 安全 | 重放/伪造/越权/SSRF | 自研/ZAP |
| 压测 | 入站/出站/WS | k6/Locust |
| 混沌 | 渠道 5xx/超时/断连 | 故障注入 |
| 一致性 | 所有适配器同一套用例 | conformance |

---

## 2. 必测场景

### 2.1 入站

- [ ] 文本/图片/文件/语音/引用/@。
- [ ] 私聊/群聊/线程。
- [ ] 重复事件只处理一次。
- [ ] 验签失败 401。
- [ ] 时间窗过期 401。
- [ ] 停用 Bot 403。
- [ ] 未绑定用户引导。
- [ ] 群聊 per_user 上下文隔离。
- [ ] 超长文本分片。
- [ ] 恶意内容拦截。

### 2.2 出站

- [ ] 文本/Markdown/卡片/媒体。
- [ ] 不支持卡片降级。
- [ ] 流式编辑/最终发送。
- [ ] 分片/转义。
- [ ] 429 退避。
- [ ] 5xx 重试。
- [ ] 幂等不重复。
- [ ] 撤回（如支持）。

### 2.3 身份

- [ ] 绑定/解绑。
- [ ] 游客限权。
- [ ] 多账号冲突。
- [ ] 跨租户拒绝。

### 2.4 健康

- [ ] Webhook 200/失败。
- [ ] WS 重连。
- [ ] 最后错误。
- [ ] 告警。

---

## 3. 一致性测试（Conformance）

每个适配器跑同一套：

```python
def test_verify_rejects_bad_signature(adapter): ...
def test_parse_text(adapter): ...
def test_parse_image(adapter): ...
def test_duplicate_event(adapter): ...
def test_long_text_chunking(adapter): ...
def test_card_fallback(adapter): ...
def test_send_retry_on_5xx(adapter): ...
def test_health(adapter): ...
```

**通过标准**：所有渠道行为一致；差异只在能力声明。

| 场景 | 目标 |
|---|---|
| 入站 100/s | 无丢失/重复 |
| 出站 100/s | 限流可控 |

## 6. 灰度/回滚

```
测试 Bot → 小群/种子用户 → 10% → 50% → 全量
```

- 观察：成功率/延迟/错误/绑定率。
- 回滚：停用 Bot/切回旧回调/降级文本。
- 记录变更。

## 8. Runbook

### 收不到消息

应用发布 → 回调 → 验签 → 事件 → 权限 → 限流 → 日志。

### 发不出

Token → 权限 → 用户/群 → 内容 → 限流 → 错误码。

### 重复

去重键 → 队列 → 多副本 → 平台重试。

### 慢

队列 → 渠道限流 → 模型 → 渲染 → 网络。
