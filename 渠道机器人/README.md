# 渠道机器人（Bot Channels）

> 目标：**一套平台，连接各种 App 的机器人**——飞书、企业微信、钉钉、Slack、Teams、Discord、Telegram、微信公众号、邮件、Web 组件、自定义 Webhook。
> 不是每个渠道写一套业务，而是「统一 Bot Gateway + 适配器 + 统一消息模型」。

---

## 1. 为什么单独成篇

已有文档覆盖了飞书，但「连各种 App 机器人」需要回答：

- 不同渠道的认证/回调/长连接怎么统一？
- 消息格式（文本/卡片/图片/文件/引用）怎么统一？
- 用户在外部 App 的身份怎么映射到平台账号？
- 一个 Bot 怎么绑定多个 Agent/租户？
- 流式输出在哪些渠道可行？不可行怎么降级？
- 如何快速新增一个渠道，而不是改核心代码？

---

## 2. 核心设计

```
外部 App（飞书/企微/钉钉/Slack/...）
        │ webhook / 长连接
        ▼
┌─────────────────────────────┐
│ Bot Gateway（统一入口）      │
│ 验签 → 解析 → 去重 → 归一化  │
└──────────────┬──────────────┘
               ▼
┌─────────────────────────────┐
│ Bot Router                  │
│ 身份绑定 → Bot→Agent → 会话  │
└──────────────┬──────────────┘
               ▼
        Agent Runtime（SSE）
               │
               ▼
┌─────────────────────────────┐
│ Channel Renderer            │
│ 文本/卡片/Markdown/分片/降级 │
└──────────────┬──────────────┘
               ▼
        Channel Adapter → App API
```

**关键**：核心只认识「统一消息」，渠道差异全部在适配器。

| 渠道 | 接入方式 | 流式 | 卡片 | 媒体 | 线程 | 群聊 | 备注 |
|---|---|---|---|---|---|---|---|
| 飞书 | Webhook/WS | 卡片更新 | ✅ | ✅ | 话题 | ✅ | 首选 |
| 企业微信 | Webhook | 有限 | 模板卡片 | ✅ | ❌ | ✅ | 需可信域名 |

| Teams | Bot Framework | 有限 | Adaptive Card | ✅ | ✅ | ✅ | Azure |
| Discord | Gateway/Webhook | 编辑消息 | Embed | ✅ | ✅ | ✅ | Bot Token |
| Telegram | Webhook/Long Poll | 编辑消息 | Inline Keyboard | ✅ | 话题 | ✅ | BotFather |
| 微信公众号 | 服务器配置 | ❌ | 图文/模板 | ✅ | ❌ | ❌ | 48h 限制 |
| 邮件 | IMAP/SMTP | ❌ | HTML | ✅ | 主题 | ❌ | 轮询/回调 |
| Web 组件 | WebSocket/SSE | ✅ | 自定义 | ✅ | — | — | 自有 |

## 5. 路线

| 阶段 | 渠道 | 目标 |
|---|---|---|
| P1 | 飞书 | 私聊/群聊/卡片/推送 |
| P2 | 企业微信、钉钉 | 国内企业主入口 |
| P3 | Slack、Teams、Discord、Telegram | 海外/社区 |
| P4 | 微信公众号、邮件、Web 组件、自定义 | 长尾/嵌入 |

**原则**：先把飞书做到生产级，再抽适配器；不要一开始做 10 个渠道。

---

## 6. 与主次编排的关系

- 渠道机器人属于 **T2 增强线**（`主次编排/07`）。
- 但 Bot Gateway 的「统一消息/身份/路由」应在 T1 就预留接口，避免飞书逻辑散落。
- 飞书可以作为第一个适配器，验证抽象是否成立。

---

## 7. 验收总览

- [ ] 一个 Bot 可绑定多个 Agent（按租户/场景）。
- [ ] 外部用户可绑定/游客使用。
- [ ] 文本/图片/文件/引用可收发。
- [ ] 支持流式或明确降级。
- [ ] 验签/去重/重试/限流。
- [ ] 新增渠道不改核心，只加适配器。
- [ ] 管理端可配置/测试/停用/看日志。
